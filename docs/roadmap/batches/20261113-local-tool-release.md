- 先生成本地私有 PostgreSQL 自定义格式备份，并通过 `pg_restore --list` 验证归档可读取；备份不进入 Git。
- 升级前版本为 `202611041530`，登记 152 个工具。实际应用 N1–N11 的 11 个新迁移，升级至 `202611131300`、163 个工具。
- Flyway validate 通过，无 Pending；再次迁移执行数为零。不修改历史 SQL 或 schema history。
- 逐项构造正式代码拥有的工具定义，并对比数据库 Schema、哈希、Handler 版本、权限集合、数据范围策略、重试、风险、确认、输出数量/字节和超时限制；11 项均完全匹配才更新启用状态。
