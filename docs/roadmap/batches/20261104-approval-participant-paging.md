## 行为与复用

新增 `GET /api/approval-tasks/{id}/participant-options?keyword=…&page=1&size=20&approversOnly=true`，返回 `Result<PageResponse<ApprovalParticipantResponse>>`。页码 1–10000、每页 1–50、关键词最长 64 字符；同时搜索展示名和登录名。旧 `/participant-candidates` 保留数组形状，委托同一领域查询返回首 50 条。

领域入口重新读取真实权限，校验租户、当前受理人、请假任务/流程/申请关联、当前实例和待处理状态；Agent 额外绑定 Gateway 提供的预期租户。非当前实例、已关闭/等待节点及其他业务类型均拒绝。既有记录若缺失当前流程关联，不会通过放松校验冒充有效待办。

SQL 共用已分配角色优先、无分配时旧角色兜底及 SUPER_ADMIN 的权限表达式，在分页前筛选有效用户、当前租户和审批资格，再使用同一条件计数。审批目标排除申请人和当前处理人；抄送可包含申请人及只读用户，申请人不会被标记为能审批自己的申请。新分页事务使用可重复读，使一次响应的总数和记录基于相同快照；真正写入仍再次验证目标资格和节点版本。

前端复用 `BusinessUserSelect`，每页 20 条、250ms 搜索防抖、滚动继续加载，支持超过 50 人的选择。共享控件增加领域关键词长度限制及失败页重试，后续页失败保留已有选项；选中项可保留安全展示标签。审批弹窗按实际操作请求服务端资格过滤，不再先截断后在浏览器过滤。旧弹窗、身份或节点的迟到查询不能进入新选择。

结果文字显示真实匹配总数、本页数量及用户可继续请求的页码。历史已完成任务没有分页元数据时仍能按旧结果展示；部分或非法分页元数据被拒绝。
