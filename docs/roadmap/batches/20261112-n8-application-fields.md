# N8 动态申请表单字段

日期范围保存为两个按时间顺序排列的 `YYYY-MM-DD` 值。多选保存为最多 20 项的选项数组。草稿可暂缺必填字段，提交时空选项数组按缺失处理。服务端拒绝无效日期、反向范围、重复选项和模板未定义的选项。

人员及部门使用十进制字符串编号。草稿回填兼容旧数据里的整数编号，并保留超过 JavaScript 安全整数范围的精度。候选查询和写入均要求当前租户的记录处于启用状态。已冻结的申请详情展示原编号，历史中的旧名称或任意对象不会被当作引用解析。

`GET /api/approval-applications/form-reference-options` 根据 `formKey`、`fieldName` 定位启用表单的人员或部门字段。支持 `keyword`、`page`、`size` 分页搜索，也支持用 `selectedId` 单独回填所选项。服务端实时检查 `route:approval-start` 与 `approval:create`，返回编号和名称。前端使用 Ant Design 选择器，选项加载按用户、租户、权限版本及表单作用域隔离。

Agent 提交预览调用与正常提交相同的前端字段转换。人员和部门需要由用户在表单选择，预览仅展示当前表单已有的值。历史详情继续遵循冻结 Schema 及敏感字段脱敏规则。

定向验证包含真实 PostgreSQL 的同租户候选、跨租户拒绝、停用部门、无权限及字段类型校验。前端字段测试覆盖日期范围、多选及精确编号回填，选择器测试覆盖迟到响应与权限变化。lint 和生产构建通过。
