## 页面与接口

“我的申请”包含请假、通用申请两个真实视图。页签按当前实际权限过滤，视图选择使用真实路由。通用申请要求 `approval:mine:read` 与 `route:approval-start`；请假要求 `leave:read:self`。列表使用既有 API，筛选及数字分页同步页面控件，通用申请最多 100 条、请假最多 50 条，不用静态业务记录。

新增 `GET /api/approval-applications/mine/{id}/fields?fieldPage=1`，沿用 `Result<T>` 与 JWT Cookie，复用既有 Agent 本人字段投影服务。领域重新检查上述两项通用申请权限；SQL 同时绑定认证租户、申请人及编号，其他用户、其他租户与不存在记录返回 404，缺权限 403，未认证 401，非法编号或页码 400。分页沿用现有两页、每页最多 50 字段的安全投影，不回传原始 Schema、流程规则或数据 JSON。

草稿明确标示按当前表单定义展示，已提交历史按冻结 Schema 渲染；不将草稿声明为已冻结。页面对字段、记录与页码回执作一致性检查。列表响应意外包含其他申请人时拒绝呈现，不能用审计权限扩大“本人”入口。
