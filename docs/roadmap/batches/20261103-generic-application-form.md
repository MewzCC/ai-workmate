# 通用动态申请表单与受控页面操作

批次 9D，依赖 `2ffc8834` 的本人申请列表及 `bdb31148` 的公共页面操作桥接。仅收口 `/oa/approval-form`；请假表单与发起审批首页继续分别交付，不混入同一提交。

## 表单与真实接口

页面使用既有申请人模板元数据接口读取启用字段与流程展示信息，不再读取管理配置全集。编辑草稿仍使用既有受保护详情接口，并在当前视图再次校验编号、申请人、表单、DRAFT 状态和可编辑标记；审计可读权限不能扩大本人编辑能力。非法草稿编号在读取或创建前拒绝，不退化成新建模式。

页面要求实时 `route:approval-form`、`route:approval-start` 和 `approval:create`；提交另需 `approval:submit`，取消另需 `approval:cancel`。这些判断只控制界面，不能替代服务端逐请求权限、资源归属、状态与版本校验。

将业务状态与事务调用移入 `useGenericApplicationForm`，视图保留 Ant Design 布局、表单与流程展示，字段转换独立复用。查询复用 `useScopedOverview`，防止旧模板、草稿与身份结果覆盖当前表单，A→B→A 也不复活旧请求。字段恢复在读取阶段完成校验，异常成为错误态和重试入口，不能在渲染 effect 中抛异常导致白屏。

日期与时间严格按规范值恢复；已移除字段不回填。金额使用 stringMode，保留原始 JSON 数值词法及用户输入字符串，避免先转为 JavaScript Number 丢失精度。选择、单选使用真实 Select/Radio 选项，数字显示模板最小值并做表单检查，最终数值与配置校验仍以服务端为准。

复杂字段尚无受控组件时明确禁用并提示联系管理员，不能用普通文本模拟文件上传或组织选择。附件、组织/人员、多行表格等完整编辑器继续属于剩余目标；本批不声明全部自定义字段能力已经完成。已存在的此类草稿值可随草稿保留，不提供新的伪造上传入口。

## 写入与确认

保存、取消与提交共用同步写锁，控件在写入期间禁用。确认弹窗使用当前 Ant Design App 上下文并绑定身份、查询、草稿版本与本地表单修订，展示实际字段及流程；待确认期间冻结编辑和 Agent 填表入口，提交使用已确认值。关闭页面或权限变化销毁本页弹窗，不影响其他页面弹窗。

新申请使用既有直接提交接口。编辑既有草稿时先保存、再提交；保存获得的新版本立即保留。第二步失败时展示真实错误，下一次必须经人工再次确认，不能使用旧版本或自动重复写入。保存后若切换身份/页面，第二步不会继续调用。已发送的服务端事务不能因前端取消等待而声称已撤销。

真实回执需匹配表单、申请人、正整数编号、目标状态和递增版本，才可展示成功或导航。具有本人申请路由及读取权限时，提交成功定位具体通用申请；否则回到发起审批入口。迟到完成和失败不修改新表单、不跳转、不显示旧身份提示。

Agent 页面指令复用 `usePageUiEditorCommands` 的白名单类型、日期转换、现有表单校验及作用域预览，只能打开空白表单、填写与查看提交预览。没有注册保存/提交回调，也没有直接调用 ToolHandler，既有工具仍经 Gateway；工具总量、权限元数据、单写规则、发布开关均未改变。
