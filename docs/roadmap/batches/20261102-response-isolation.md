# 身份与权限变化后的请求响应隔离

## 范围

统一认证请求关联，不包含聊天缓存/任务恢复、页面工具或业务候选查询。暂存版本已剔除同文件内上述业务改动，工作区原内容保留。

- AuthProvider 关联身份与有序权限快照，失效的恢复登录/退出回调不得替换新用户。
- 11 个 API 客户端统一处理响应体和认证错误。JSON、文本、Blob、XHR 和 SSE 在交付时校验原作用域；旧 401/403 不退出新账号。
- 失效响应不读取私有 JSON，释放未消费的响应体和流式 reader。作用域变化使用双语明确错误，不视为业务取消、失败或可重试依据。
- 用印附件兼容可选的视图作用域检查，防止迟到上传或下载在替代视图中生效。
