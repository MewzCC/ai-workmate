## 共享领域服务

`TodoQueryService` 同时服务正常 Controller 和本地 Agent Port Adapter。查询按认证用户、租户及本人受理关系限定，只支持 LEAVE_APPLICATION、GENERIC_APPROVAL 两类已实现流程；实例、业务、申请人与租户关系同时校验。查询和计数复用同一 SQL 关系与过滤条件，并在只读可重复读事务中完成，混合业务先统一排序再分页，不拼接两页假装全量。

| 接口或工具 | 行为 |
| --- | --- |
| `GET /api/todos` | 默认全部支持业务的 PENDING；允许 businessType、status、from、to、page、size；每页最多 50、页码最多 10000 |
| `GET /api/todos/{id}/summary` | 仅本人受理任务的受保护摘要，用于安全判断详情种类，不返回申请原始数据 |
| `GET /api/todos/{id}` | 保持请假专属详情，拒绝通用任务编号 |
| `todo.query` | 保留同一工具代码，通过现有 Handler → Port → 领域服务读取两类业务，返回实际应用的筛选条件 |

历史通用标题仅从该实例的可证明快照读取，不退回当前申请标题；缺少历史快照返回业务编号并标记详情不可用。请假摘要在原实例已不对应当前提交或申请恢复为草稿时不展示新草稿的类别、时长。通用任务不伪装成请假时长。返回受控头像接口地址，不返回内部存储键或申请原始内容。

## 前端与结果

我的待办默认“全部待办”，保留请假、通用申请页签。页面使用 Ant Design、ResponsiveTable、统一移动断点和已有请求作用域保护。记录详情先查当前受保护摘要，再调用匹配的业务详情接口验证任务和申请编号，之后才导航；撤权、换筛选或迟到响应不能导航旧记录。

`todo.query` 返回业务范围、节点状态、日期、页码与大小。完成后的导航只接收这些经过封闭 Schema 的值，在固定 `/oa/todo` 路由重建筛选，不读取输出 URL，不使用模型参数选择业务记录，仍按最新菜单权限过滤。小窗和工作空间可复用同一构造函数。旧已完成结果保留兼容展示；不改写历史冻结计划。

中文、英文结果同时展示实际任务编号、申请人、业务类型、通用标题与节点、当前节点状态、期限及逾期。筛选无结果时说明本次范围，避免把历史查询说成“没有待处理事项”；回复限制展开数量并提示其他任务仍需查看。
