# 资产分配候选工具

本批依赖已经提交的资产候选领域接口、资产页面及 `c2ff40a5` 的工具基础，独立接入部门与保管人只读工具，不混入其他业务表单和浏览器指令处理器。

## 行为与边界

- `asset.department.query` 使用姓名或编码关键词分页搜索同租户有效部门，不要求先猜资产或部门编号。资产所属部门查询仍须通过 `asset.query`，不能以部门名称搜索替代。
- `asset.custodian.query` 在指定的有效同租户部门内分页搜索有效用户，只返回编号、姓名和部门编号。重名候选全部保留，不自动选取第一人，不授予人事管理或全局用户目录权限。
- 两个工具均为 L0、无副作用、单次最多 20 条，并要求 `asset:write`、对应工具权限和资产页面入口。Workspace 继续受业务页面权限约束，所有调用仍由 Tool Gateway 分派。
- Port/Adapter 复用既有 `AdminAssetsService`，将 Gateway 可信租户传入领域查询；领域重新解析当前用户权限后比较预期租户，再将租户条件写入查询。普通页面 API 的原签名和返回值保持兼容。
- 前端维护两项双语工具目录和固定资产页导航。候选的人员或部门编号不能被误当作资产编号；没有实时资产页菜单权限时不能导航到该页面。
