# 聊天任务持久关联与终态恢复接口

积压批次 5A：对应 A01/A02/A03 的服务端部分，不包含前端聊天状态机、页面工具、原子申请工具或通用业务国际化。

## 行为及接口

- `POST /api/ai/tasks/plan` 接受可选正整数 `conversationId`。只能为当前认证用户、租户的 Workspace 会话规划任务；规划与会话删除共用会话行锁，已有未完成任务时拒绝再开新任务。
- 新任务写入既有 `agent_task.conversation_id`，成功规划时持久保存用户输入。该字段由既有 Flyway 迁移创建，本批无结构迁移。
- `GET /api/conversations/{conversationId}/agent-task` 返回最近关联任务的真实详情或空值，服务端检查当前会话所有权；不根据浏览器缓存恢复任务身份。
- 结果追加继续锁定会话和任务并按来源任务幂等。已关联任务不得追加到另一会话；用户输入不重复写入。真实失败、取消、超时、拒绝、过期与结果未知保存各自终态说明，未完成任务不得伪造完成消息。
- 删除存在未完成任务的会话返回业务拒绝，不把删除会话当成取消任务或回滚业务。
- 新文案同步默认、简体中文和英文资源；现有鉴权、统一响应与 Tool Gateway 不变，不开放任何新写工具。
