# 会议预约完整分页与表单状态保护

积压批次 6A，对应 A04/A16/A17，并提供后续 A07/A14 复用的公共分页加载器。不包含候选接口、页面工具或会议室基础资料编辑。

## 行为

- 预约按日历显示月份及相邻日期查询，加载全部分页，拒绝以首 100 条冒充完整范围；本人和管理数据按当前权限分别查询。
- 公共 `collectPagedRecords` 每次请求前后绑定原身份/权限快照，跨页总数变化、非法总数、超长分页、超出总数、提前空页或超过预算均失败；失败不返回部分列表。它只能检测分页契约和身份一致性，不保证没有服务端快照标识的接口在并发修改时具备强一致分页。
- 跨天预约投影到所有实际占用日期，午夜结束不多算次日；切月或切身份后的旧响应不覆盖当前视图。
- 预约入口与取消按钮按实时权限过滤；旧权限下的取消回执不更新新视图。管理者不必额外具备本人预约读取权限。
- 预约表单复用现有同步锁，在校验前锁定，校验错误留在字段旁；双击只发送一次创建。关闭等待中的表单可重新打开草稿，旧回执不关闭或改写新草稿，关闭不表示服务端取消。
- 新增分页失败文案同步简体中文和英文。日历、表单和按钮继续使用 Ant Design，不引入依赖。

会议预约检查覆盖完整分页、跨天和午夜、只管理权限、操作权限、切月迟到、后续页失败、旧取消回执、预约校验及双击/关闭/替代草稿。此为 API 夹具的前端交互证据，不是新一轮真实 PostgreSQL 大预约列表、真实冲突并发或 PC 各分辨率浏览器验收。

## 风险与回滚

并发修改导致跨页总数变化时会要求刷新；这是拒绝展示可能不完整的数据，不能回退展示第一批记录。可独立撤销本批；公共加载器被后续批次引用后，应先撤销调用方。无数据库迁移或发布开关回滚。
