## 变更

- 新增资产的指定部门、人工领用/调拨目标、Agent 领域领用的员工部门，必须属于当前租户且处于启用状态。
- 在业务事务中使用固定参数查询 `FOR SHARE` 锁定有效部门，拒绝无效目标，并让部门状态更新与当前分配事务协调。无任意 SQL 或通用执行入口。
- 盘点只记录实际观察位置，不自动改写资产所属部门；保留记录既有非启用部门实际位置的原有能力，不以新增分配校验阻止如实上报盘点差异。
- 已成功操作的幂等回放仍先返回原回执，不因为事后部门停用而重复写入或伪造失败。
