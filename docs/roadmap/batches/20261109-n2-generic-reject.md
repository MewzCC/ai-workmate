# N2 通用审批受控驳回

基线 `13a55a62`，实施依据为[业务缺口计划](../20261109-missing-business-capabilities.md)的 N2 / G02。

## 合约与实施

- 一个驳回工具只处理当前处理人的一个通用审批任务，要求任务版本和明确理由；租户、身份、权限不接受模型参数。
- 复用 `GenericApprovalTaskService.reject` 的事务、冻结流程检查与审计，不新增通用远程调用或绕过 Gateway 的入口。
- L2 二次确认、禁止自动重试，迁移注册默认关闭；独立工具权限与领域 `approval:act` 都需要实时满足。
- 驾驶舱的通用预审仅绑定已有冻结详情读工具，并额外要求待办入口权限；提示明确业务类型且不执行审批。

## 接口与数据

工具代码 `approval.genericTask.reject`，独立权限 `agent:tool:approval.genericTask.reject`，领域权限 `approval:act`，入口权限 `route:todo`。输入为 `taskId`、任务 `version`、1–500 字符 `comment`；空白理由由 Handler 和领域服务拒绝。缺少确认凭证沿用任务接口的 409 响应，不伪造执行结果。

回执包含 `applicationId`、`taskId`、任务 `status=REJECTED`、递增后的任务 `version`、整单 `applicationStatus=REJECTED` 和 `action=REJECT`。不携带表单原始数据、对象路径、角色或凭据；前端只按当前授权菜单进入固定通用任务路径。中英文回执明确整单审批已结束，不会继续生成下一节点。

新增迁移 `V202611091000`，冻结 Schema 哈希 `sha256:902b48b79d40b1538db4e8937e4e1d14bb6f428caa2e7ec60b3d84c61272b96d`。不修改既有工具 Schema 和历史迁移，不打开全局或租户写开关。代码登记不等于已完成真实模型或人工发布验收。
