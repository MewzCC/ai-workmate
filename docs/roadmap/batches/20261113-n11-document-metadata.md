# N11 业务附件元数据读取验收记录

N10 已独立提交为 `50531f7e`；本节点仅补员工档案和用印留档的受控元数据查询，不上传、下载或解析文件内容。

## 固定边界

- 输出仅包括十进制字符串文件编号、业务文件类型、展示名、MIME 类型、大小和创建时间。
- 不输出存储键、对象路径、contentUrl、上传者身份、密钥或文件内容。
- 两个工具固定绑定各自领域；模型不能传租户、操作者、权限、业务域选择器或 URL。
- 员工工具沿用员工档案工具的 `hr:read` 准入，领域再复核员工可见范围；现有人工作业的本人读取规则保持不变。
- 用印工具沿用 `seal:register`，领域再复核关联用印资源，不扩大到任意租户文件。
- 每页最多 20 条、页码最多 10000，数据库分页并按创建时间和编号稳定排序；不先取全量文件或用户再截取。
- 上传与人工下载继续走现有受认证接口，不增加 Agent 二进制或文件系统能力。
