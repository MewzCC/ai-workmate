承接 `ee023d32`，为已查到的通用任务提供受控详情读取和真实详情导航。按照一个原子工具一个提交，本批仅新增 `approval.genericTask.detail.query`；通过、驳回以及其他写工具继续独立交付，整体全页面读写目标保持不变。

## 合约及复用

输入只有正整数 `taskId` 和可选 `fieldPage`（1–25），身份来自 Tool Gateway。输出包括任务/申请编号、冻结标题、申请人、节点、节点状态与任务版本、整体申请状态、时效、分页允许字段和当前可操作标志。`version` 属于当前任务，不是申请版本。

新增类型化 `GenericApprovalTaskToolPort`、本地 Adapter、类型化只读 Handler，复用 `GenericApprovalTaskService` 的快照投影和业务状态判断，不复制流程引擎。Port 只使用 Java 标量、记录与列表，不携带 JSON、Map、框架 DTO、URL 或调用凭据；后续远程 Adapter 可以替换传输，但不能扩大权限。

普通详情仍为每页 50 字段、最多 2 页。Agent 详情每页 4 字段、最多 25 页，最多 100 字段全部可分页读取，无静默裁剪。四字段窗口使每字段最多 20 个、每值最多 500 字符的最坏 JSON 转义内容仍在 262144 字节的工具上限内；数组上限 20，结果还必须经过 Gateway 的 Schema、字节、条数及内容校验。文字摘要可缩略并明确提示查看详情，不修改结构化结果；摘要提示后续字段页。

新工具仅绑定待办页和 AI 工作空间。工作空间同时要求对应业务页面权限。前端只使用已成功结果中的有效任务编号，在最新菜单权限内进入固定 `/oa/todo?kind=generic&taskId=...`，不信任模型参数、返回 URL 或申请编号代替任务编号。

## 权限和历史隔离

工具为 L0、ASSIGNED_TO_SELF、READ_ONLY_SAFE、无副作用、无需写确认。要求 `todo:read` 和独立 `agent:tool:approval.genericTask.detail.query`；Gateway 重新解析实时权限，领域服务再次校验认证用户、期望租户和任务受理关系。申请人、抄送人、审计人员不会因其他只读身份获得本工具的他人任务读取权。

冻结 Schema 和数据只来自 `approval_execution`。读取和已有审批决定共同校验快照实例、租户、申请及申请人与业务任务一致，缺失或关系不一致拒绝。当前草稿、当前表单配置和未注册字段不能替代历史数据。敏感字段、密钥字段、附件及不支持字段按现有投影隐藏；不返回原始 Schema、流程规则、审计全集或内部存储位置。
