# 发起审批首页与共享生命周期操作

批次 9F，承接 `c65b3da9` 的申请表单交付，仅收口 `/oa/approval-start` 及与“我的申请”直接共享的生命周期操作、本人字段详情组件。其他业务页面与后端国际化改动继续分别提交。

## 权限、模板与本人申请

页面使用实际 `route:approval-start` 权限。模板查询另要求 `approval:create`，本人摘要另要求 `approval:mine:read`，两个读取区独立加载与报错；缺一项权限不再触发另一项无权请求或让整个页面不可用。请假快捷入口只依赖实际 `leave:create` 和 `route:leave-application`，是既有页面导航配置，不虚构数据库模板或业务记录。

模板通过申请人元数据接口收集全部分页，延续共享分页总量一致性及读取上限；离开页面或身份变化后停止继续翻页。关键词与精确 formKey 分开处理，界面显示精确筛选标签。打开前重新读取该模板，核对真实编号和键及目标路由权限，已下架、替换或不再有权进入的模板不能沿旧卡片导航。预检期间换筛选、换身份、卸载或开始写操作，旧响应不能跳转。

草稿和近期申请沿用既有本人 API，拒绝其他申请人混入。首页明确展示摘要窗口：最近 20 份草稿和最近 20 份申请中的已提交记录；完整记录进入已交付的“我的申请”分页页面。未获完整列表路由时明确提示入口未开放，不将摘要称为全部数据。继续编辑前重新校验详情的本人归属、DRAFT、表单键和可编辑标记。

## 共用操作与详情

提取 `useGenericApplicationActions`，首页与 GenericApplicationsPanel 共用提交、取消、撤回、恢复编辑、催办的真实权限、合法状态、确认框、同步写锁及回执检查，避免各页重复维护同一状态机。首页使用撤回、恢复编辑、催办三项；既有“我的申请”继续保留五项。确认时核对当前已加载行版本，服务端继续执行最终乐观锁校验；真实结果需匹配本人、表单键、编号、目标状态及递增安全整数版本。失败只重新读取业务状态，不自动重复写入。

提取 ApplicationFieldsModal，两个入口均使用既有 `/approval-applications/mine/{id}/fields` 的字段投影，每页最多 50 字段，并按快照/当前草稿显示不同说明。前端不再解析原始 schema/data JSON 展示历史详情，遵从返回的字段遮盖标记。提交时间类型与服务端既有投影对齐；流程版本来自当前本人列表的冻结版本，缺失时明确显示空值，不推断或伪造。

详情关闭、切换字段页、换身份及卸载后，迟到字段不能重新打开弹窗或回写其他记录。已知写操作后刷新同一详情并重置字段分页；所有弹窗沿用当前 Ant Design App 主题及作用域保护。静态角色推断、通用管理配置全集与假成功均未参与这些流程。

## Agent 界面指令

首页只注册实际可用的刷新、白名单筛选及模板编号打开指令。刷新任一区读取失败会拒绝本次界面操作；模板编号只接受正安全整数，不能以模型参数 URL、字符串编号或卡片点击绕过目标路由授权。命令不包含任何业务写回调，正式 Agent 写入仍经已有 Tool Gateway、单写步骤及发布门。本批没有新增工具、HTTP 路径、数据库迁移、依赖或改变工具开关。
