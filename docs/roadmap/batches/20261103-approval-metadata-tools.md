# 审批只读元数据工具批次

积压批次 7A。一次提交同一业务依赖链：代码目录、领域 Port/Adapter、Handler、Schema、页面白名单、两份已有迁移、结果文案、前端固定导航及对应回归。原子申请写入、页面指令和人事/访客/资产候选工具继续分别提交。

## 实际能力

| 工具 | 读取范围 | 权限与限制 |
| --- | --- | --- |
| `approval.application.template.query` | 已启用的本租户申请模板；指定表单标识后读取语义字段及流程版本 | `approval:create`、工具权限及发起审批入口权限；工具每页最多 20 项 |
| `approval.process.definition.query` | 一个授权流程的语义节点、表单关联、状态及版本 | `approval:read`、工具和来源页面权限；校验预期租户，最多 20 个节点 |
| `approval.task.participants.query` | 当前分配给本人的待处理审批的协作候选人 | `approval:act`、工具和来源页面权限；最多 50 人，可用关键词缩小范围，区分可审批及仅可抄送 |

三个工具均使用已有 `TypedReadToolHandler`，经真实 Worker 和进程内 Tool Gateway 执行，领域服务再次检查当前权限、资源、租户及业务状态。没有增加公开通用工具执行接口，不授予候选人审批权限，不改变写工具开关。

模板同时提供 `GET /api/approval-config/application-templates`，返回 `Result<PageResponse<ApprovalApplicationTemplateResponse>>`。普通申请人可读发布后的模板，不需开放审批管理权限；原始 JSON、创建人身份和流程处理目标不通过申请模板预览返回。前端 API 类型、三个工具的中英文名称、可读结果摘要和固定业务导航同步，外部 URL 或模型参数不能决定页面或记录。

## 数据与实现

- 表单字段复用既有语义 Schema 校验；流程预览与管理员流程读取复用同一节点解析，不重复拼装另一套任意 JSON 协议。
- 公共候选分页参数校验复用于模板查询。流程 JSON 限制 64 KiB、3–20 个节点，拒绝重复键、尾随数据和非法结构；不能发布的定义明确失败，不返回伪造的有效节点。
- 读取结果使用真实字段、版本和节点名称生成有上限的中英文文字，协作候选明确标记仅可抄送的人员。
- `V202610271000` 和 `V202610271001` 是此前工作区中已在本地开发环境执行、尚未归入提交的迁移，保留原名称及全部文本，不改历史版本。两文件原有末尾空行亦保留；仅对这两文件豁免 Git 的 `blank-at-eof` 提示，其余空白检查照常执行。
- 本批暂存快照目录为 `backend/target/chat-server-review-5qm8k0zq/`。开发库中更后续的工作区迁移仍待其他批次归入版本控制；不删除其 schema history，也不以局部提交对开发库降级。部署前须完成剩余依赖收口。

## 限制及回滚

测试的冻结计划用于隔离验证 Worker/Gateway，不代替真实模型规划或浏览器验收。候选和模板返回声明的有限集合，参与人超过 50 名时需细化关键词；完整页面命令、其他领域候选及单句原子提交仍在后续批次。

回滚时优先关闭相应只读工具或撤销其授权，再回滚调用方及代码；已执行的迁移不删除、改名或改校验和，数据库修复通过新的前向迁移完成。本批没有开放写工具发布门，也没有绕过单写步骤、确认、审计和租户边界。
