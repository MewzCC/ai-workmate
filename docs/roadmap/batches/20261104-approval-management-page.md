# 审批中心与节点办理交互

批次 9G-2，承接 `92254385` 的任务读取隔离，仅提交审批中心、请假节点详情抽屉/完整页面及其共用读取、人工操作和双语文案。通用申请审批闭环 A25、流程配置、其他页面和后端国际化继续独立提交。

## 本批行为

- 审批列表复用认证查询快照，按用户、租户、实时权限及筛选版本隔离结果。读取或统计失败时清除旧记录/指标，显示错误与重试；撤权立即移除旧列表和详情。
- 搜索输入草稿与已应用关键词分开，Enter、搜索和清空使用当前输入值。分页使用真实数字，支持 10/20/50 条；页面指令校验类型、范围、状态及本地日期，日期选择器同步受控值。统计仍为服务端全范围口径，分页总数代表当前筛选。
- 行预览和完整详情导航先调用受保护详情，核对实际任务编号及申请编号；禁止把字符串强制转成编号。关闭、切筛选、换身份及后发请求使旧打开请求失效，不迟到重开抽屉。
- 抽屉和独立详情共用 `useApprovalTaskDetail`，同时读取同一请求节点的详情与时间线；请求节点不符、读取失败、关闭或身份变化均不能保留旧详情。
- 两处人工审批共用 `ApprovalTaskActions`，以真实 `approval:act`、服务端可处理标记、本人当前处理人、待处理节点及版本决定入口。完整页面保留转交、抄送和前/后加签，预览继续提供通过/退回。没有将写回调注册成页面 UI 指令。
- 确认框展示实际申请、任务和节点版本。先取得同步锁再校验表单，操作前重新读取任务并比较申请/节点版本和处理权限；版本变化只刷新，不自动写入。写入期间禁止重复确认和表单编辑。回执核对申请及状态，通过后仍有下一节点时明确说明，未知结果不伪造成功或自动重试。
- 协作选人改为服务端关键词查询，并按操作类型过滤审批资格；候选失败有独立错误与重试。现有候选接口每次最多 50 人，界面明确提示缩小搜索，完整候选分页仍是后续工作，不能把首批结果称为全体用户。

## 接口与权限

沿用 `/api/approval-tasks`、`/stats`、`/api/todos/{taskId}`、任务 `/timeline`、`/participant-candidates` 及人工审批/退回/转交/抄送/加签接口，没有新增接口、迁移或工具代码。详情读取由服务端校验真实资源关系；前端不以 `todo:read` 代替该关系校验，抄送者等合法只读人仍能读取。

Agent 只注册现有白名单筛选、刷新与受保护详情预览，没有直接提交 UI 工具。领域写接口、Tool Gateway、单写步骤、租户、确认和发布开关保持原有约束；本批没有开放任何写发布门。
