# 聊天任务恢复与身份缓存隔离

积压批次 5B，配合服务端 `fa833bca`。不包含页面工具处理器、业务候选接口或新原子写工具。

## 变更

- Workspace 规划传递会话编号，读取服务端最近关联任务；待确认任务恢复原计划，排队/运行任务只观察，终态读取并保存真实回执，不因刷新重新规划、签发确认或执行。
- 统一状态卡区分失败、取消、超时和“结果待核对”；本地观察达到预算保留服务端快照与刷新入口，不表示业务失败。
- 取消最多发送一次命令，必要时只读核对。身份或权限变化后停止旧核对和观察，不用新账号继续读取旧任务。
- 聊天缓存按认证用户和租户隔离，同身份刷新和普通路由切换保留会话状态；旧异步回调及旧动作不能进入新身份，退出不隐式取消服务端任务。
- 业务任务消息与本地操作占位不显示普通聊天的重新生成入口，防止重复写入；排队/待确认任务在观察期间仍可取消，运行中不开放强制取消。
- 聊天阅读区设可收缩 Grid 列，防止恢复后的长内容撑宽页面。同步简体中文和英文状态说明。
