# 浏览器受控页面操作桥接

积压批次 9A，依赖 `c2ff40a5` 的服务端 `page.ui.prepare` 合约。本批提供浏览器公共桥接、任务入口和未提交表单共享 Hook；业务页面逐页注册筛选、详情和编辑处理器继续独立提交。

## 实际变化

- `AdminLayout` 持久挂载一个按认证身份隔离的桥接器，页面路由切换保留桥接器与侧栏；切换账号不复用旧注册、任务回执和表单实例。在 OA 自身 ConfigProvider 内提供不增加 DOM 容器的 Ant Design App，使共享预览使用当前 OA 弹窗上下文。未混入工作区中另外的壁纸修改。
- Drawer 与 Workspace 接收实际成功任务中的页面准备结果。普通业务结果仍保持原有终态刷新；含页面指令的任务不先刷新并销毁待填表单，也不与普通结果导航同时争用路由。
- Workspace 只自动应用本次观察到执行中并最终成功的任务。恢复已经完成的历史记录保持只读，不因重新进入会话、语言变化或刷新浏览器重新执行界面操作。
- 固定协议仅包括导航、筛选、详情、创建未提交表单、填表、预览和刷新。没有 DOM 选择器、脚本、任意 URL/HTTP，也没有提交、保存、审批或权限修改回调。

## 权限、时序与实例边界

每条命令应用前重新加载真实导航和当前页面能力，要求页面仍可访问、响应页面匹配、命令仍在目录内、`page.ui.prepare` 工具本身仍可用。不能只用旧任务成功状态或页面路由权限保留被撤回的能力。

桥接器记录本地页面切换次数和认证/授权数据范围。异步等待期间发生权限变化、账号切换、页面 A→B→A 或所属实例卸载均拒绝迟到指令；桥接器自己发起并实际完成的单次受权路由切换可以继续同任务后续步骤。业务处理器还须使用自己的请求和表单作用域保护异步页面状态，桥接器不能替代领域接口的实时鉴权。

同一任务步骤回执在内存去重，同时只应用一个任务。最多保留本次挂载中的 100 个任务，不通过淘汰旧回执而允许历史指令重放；达到上限要求刷新并重新发起。此限制只限制本地页面交互，不是服务端业务执行预算或任务取消。

表单填充和预览必须绑定当前会话、记录编号及版本，或同一任务刚打开的新表单。用户编辑、关闭、换记录和权限变化均使原实例过期。多视图页面只能由显式注册的视图选择器切换，后续步骤绑定实际视图/资源键；缺失或冲突的处理器失败关闭，不能搜索 DOM 兜底。

`usePageUiEditorCommands` 复用字段白名单、严格标量/枚举类型、日期转换、既有 Ant Design 表单校验和按标签裁剪的预览；不接受提交函数。预览 Hook 使用 Ant Design App 的弹窗上下文，在所属表单或身份作用域变化和卸载时仅销毁自己的预览，不关闭其他页面的弹窗。
