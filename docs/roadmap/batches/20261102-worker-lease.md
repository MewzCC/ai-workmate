# Worker 租约与取消领取竞争修复

对应统一清单 A21，并补充 A01/A03 的数据库级证据。

## 变更

- 完成、失败、未知结果及只读重试均先锁定任务，检查运行状态、Worker、租约、任务期限和 attempt，再修改步骤；无效请求不改变任何一方。
- 心跳不得延长已过期租约；到期任务不得开始下一步或回写完成。
- 取消与队列领取继续使用现有状态和版本条件，不开放运行中强制取消，不重放结果未知的写入。
- 无 DTO、公共接口或数据库结构变化；不修改历史迁移或工具发布开关。

## 验证

- 后端关联组 67 项通过；新增场景随后纳入默认后端全量：1922 项、0 失败、0 错误、1 跳过。唯一跳过为旧初始化脚本用例缺少 Docker；本批真实 PostgreSQL 检查没有跳过。
- Worker 持久化 37 项检查包含 28 组失效身份/租约/期限/attempt 组合、4 种当前租约正向转换、失效心跳和只读换租约恢复。
- 取消与领取竞争执行 8 轮真实并发，核对唯一胜者、步骤状态和零工具调用。它证明数据库仲裁，不代表已完成所有真实 Worker 运行中故障或进程重启验收。
- 日志：本地 `backend/target/worker-lease-batch.log`、`worker-lease-full-repeat.log`。全量首次发生两个生成 class 文件读取失败；禁用编译器增量判定后完整复跑通过，未删除源码或原有本地备份，未确认文件读取失败的稳定原因。
- 使用测试框架自建 PostgreSQL 数据库/schema 和随机端口 Redis，不修改开发库或用户 Redis。

## 风险与回滚

晚到的 Worker 回执将被拒绝，后续由既有租约恢复判定结果；不能把被拒绝的回执解释成业务未发生。任务行先于步骤锁定，与恢复路径保持一致。可独立撤销本批源码和测试，无结构回滚；回滚会重新引入旧租约回写缺口。
