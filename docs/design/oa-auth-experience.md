# OA 登录入口视觉更新

正式入口保持 `/oa/auth`；官网 `fronted-main`（3000）与 OA `fonted-oa`（3001）仍独立运行。

`AuthExperience` 提供全屏浮岛背景、移动磨砂遮罩、双面表单卡片、左右翻转、镜像文案和首次缓入。背景图为本次设计生成的本地素材。减少动态效果偏好下关闭动画，移动端使用项目统一的 720px 断点切为上下布局。

`AuthPage` 继续持有原有真实密码登录、邮箱验证码登录、验证码注册、图形验证码、冷却时间、风控验证码、服务协议与隐私政策、找回密码和安全跳转逻辑。两个表单面使用独立 Form name，非活动面 inert，不允许键盘进入。页面没有预览提交逻辑，也不返回模拟登录成功。

语言入口复用 `LanguageSwitcher` 的 Ant Design Dropdown 菜单，不使用 Select 或二选一切换。文案由 `authDesign` 与原有 `auth` 中英文资源提供；语言持久化、Ant Design locale 和请求 Accept-Language 复用现有全局实现。

官网主要 CTA 同步已确认的玻璃胶囊样式，保留原有文案与进入 OA 的跳转逻辑。

验证：遵照用户在本轮设计迭代中的明确要求，本次正式接入未运行测试、lint 或 build；实际登录、注册、重置密码和布局需由用户本地验收。后端及数据库没有改动。
