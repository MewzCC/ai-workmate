# 审批规则定义只读工具

## 目标与调用链

基线 `f8dd6cd4`。原规则页详情客户端只服务界面，`approval.configuration.query` 只返回摘要，
两者不能冒充 Agent 已能读取规则条件。新增 `approval.rule.definition.query` 补齐这一实际缺口。
调用仍为持久任务 → ToolGateway → 类型化只读 Handler → ApprovalConfigurationToolPort → 本地 Adapter → 领域读取。
不新增公共执行或 HTTP 详情接口，不绕过 Worker、网关或领域鉴权，也不执行规则动作。

## 有界契约

输入仅为正整数 `ruleId`；用户、租户、角色和其他属性拒绝。
返回规则 ID/键/名称/类型、优先级、状态、版本、AND/OR 逻辑、最多 10 个明确条件与一个明确动作。
条件和动作复用已冻结规则草稿的语义属性约束，不返回原始 JSON、无关说明、创建人或身份信息。
读取优先级兼容普通业务允许的全部非负 Java 整数；写工具 10000 上限保持不变，不用写限制缩窄读取。
每份源定义最多 64 KiB；严格拒绝重复 JSON 属性、尾随内容、未知扩展、错误类型、缺失字段和超限值，
不以过滤掉扩展后返回部分规则冒充完整读取。普通界面详情仍保留原显示能力。
兼容真实种子的平铺条件，解释为 AND 单条件；动作仅在 mode 属性缺省时返回既有 OR_SIGN 默认语义。
显式 null 不等于缺省；enabled=false 必须原样保留。数字条件以精确十进制字符串返回，不经浮点舍入。
读取采用当前认证权限和可信租户核验，SQL 同时限定租户、记录及非删除状态，不更新版本、不写业务审计。

## 注册、结果和导航

L0、NONE、READ_ONLY_SAFE、固定资源范围、业务 approval:read 和独立工具权限；Workspace 还要求实际规则页路由权限。
迁移 `V202610241615` 注册只读工具和业务读取权限对应的候选角色绑定，不启用任何 Agent 或写开关。
冻结 Hash：`sha256:a595eafd0035099b68fcf7f97867ea848d13cb214cd2bceda203936fd2031b23`。
数据库验证比较 Schema 树及真实 Bean 的冻结 Hash，不对 jsonb 重排后的字符串重新计算 Hash。
代码工具目录为 139 个（41 读、98 写）；登记、运行可用和真实模型验收是不同口径。
双语确定性摘要展示实际条件、动作、优先级、版本及独立的规则状态，动作开关不等于规则启用状态。
摘要按完整条件行限量，遗漏行明确计数；不删改下划线、括号或长数值，不反馈 Planner。
Workspace 中带实际任务/工具来源的结果改为纯文本，与 Drawer 一致；普通聊天继续 Markdown。
这防止把业务值当作图片或链接执行，也避免为安全而静默改写业务条件。
成功读取以真实 ruleId 复用规则受保护详情定位，不采用模型 URL、参数猜测或查询第一行。

Ruling: 使用规则草稿已有封闭语义而非任意 JSON 读取——完整展示当前受支持规则且不会隐藏未知副作用；
代价是带未知扩展的历史定义明确拒绝，需要单独评审扩展，而不是自动降级。
Ruling: 读取兼容已发布种子缺省 mode 和平铺条件，但不修改原记录——保持当前解释语义；
代价是不能据此声称新增的任意规则格式也被支持。
Ruling: 分离共享语义验证与写专用优先级上限——读出已有合法值不应受写发布范围约束；
代价是新增读取契约需独立冻结，但不得改动任何已发布写工具的 Hash 或边界。
Ruling: 工具结果统一纯文本而不是对业务值删字符——保证结果准确且不将值解释为图片/链接；
代价是工具摘要不再提供 Markdown 排版，普通聊天及知识库回答保持原样。

## 限制与回滚

真实模型、完整 Worker、浏览器和发布门仍待验收；本地 Redis 尚未恢复。
此前 Docker Desktop 启动后本地 socket 访问失败并退出，未删除 Docker 文件、安装 WSL 或放宽依赖失败关闭。
规则局部修改仍需独立原子命令；本工具不允许结果递归规划、执行动作或拼接多写。
回滚同步撤回代码目录、类型化契约、摘要与结果导航，按管理流程停用新工具及绑定；保留已执行迁移。
