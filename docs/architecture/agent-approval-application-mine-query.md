# 本人通用申请摘要查询工具

`approval.application.mine.query` 补齐“我的申请”中通用表单读取缺口，与 `leave.mine`
分别返回真实数据，不把请假列表当作全部申请。默认无状态、表单过滤，第 1 页、20 条；
页码最多 10000，每页最多 50，可筛选 DRAFT/PENDING/APPROVED/REJECTED/WITHDRAWN/CANCELLED。
不接受租户、用户、权限、任意表达式或网络目标。

## 分层与权限

复用 `ApprovalApplicationToolPort`、本地 Adapter 和 `GenericApprovalService.mineForAgent`。
领域入口再次检查实时 `approval:mine:read`，原有本人查询仍检查 `route:approval-start`，
实际 Mapper 同时限定 tenant_id 和 applicant_user_id。工具另要求独立权限
`agent:tool:approval.application.mine.query`；代码定义为 L0 / SELF / NONE，结果上限 50 条、32768 字节。

新增迁移 `V202610091100` 将业务读权限和工具权限授予已有发起审批路由权限的角色；
不扩大到其他申请人，不改历史迁移，不放开写开关。未来服务化只替换传输无关 Port 的
固定目标 Adapter，所有 Agent 调用仍由 ToolGateway 分派。

## 结果与交互

返回申请编号、表单名称/键、状态、版本、时间、逾期/催办及可操作状态标志。
不返回 title、dataJson、Schema/规则/节点快照、申请人或审批人身份、附件与流程内部坐标。
可操作标志沿用页面状态判断，不构成写授权；具体写入仍须实时业务权限、网关和领域状态校验。
文字摘要显示真实总数、申请编号、表单、翻译后的状态和版本；使用既有固定页面导航进入
“我的申请”，导航仍过滤实时菜单权限。当前仅列表摘要，不声称已经提供历史表单详情读取。

## 验证及回滚

定向测试覆盖冻结 Schema、未知身份、分页上限、类型错误、可信上下文、空结果、失败无 fallback、
摘要脱敏与原始字段不读取。真实 PostgreSQL 门禁执行实际 Mapper → Service → Adapter，
验证同租户其他员工及另一租户记录排除、状态/表单筛选、分页总数及权限撤销失败关闭。

回滚优先禁用单工具或撤销其独立权限，保留迁移与任务审计。未完成真实模型和浏览器端到端
验收时，不将代码注册数量解释为全页面能力可用或写发布门完成。
