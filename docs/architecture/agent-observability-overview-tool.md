# 平台观测聚合查询工具

`observability.overview.query` 在现有平台观测服务之上提供真实聚合能力，不用日志列表条数
代替调用总量，不生成 Mock 图表。输入只接受 `range=24h/7d/30d`，默认 7d；不接受任意
起止时间、用户、租户、查询表达式或导出参数。

## 分层与权限

Handler → 类型化 `ObservabilityToolPort` → 本地 Adapter → `PlatformObservabilityService`。
查询为 L0 / TENANT_SCOPED / NONE / READ_ONLY_SAFE，独立权限
`agent:tool:observability.overview.query` 与实时业务权限 `runtime-log:read` 必须同时满足。
领域 Service 另要求 `route:platform-observability`，根据实时认证用户取得当前租户，并在
所有聚合 SQL 中过滤租户；不能用工作空间入口扩大用户原有访问范围。

工具绑定平台观测和 AI 工作空间。所有 Agent 调用继续经 ToolGateway；未来服务化只替换
固定目标 Adapter，不开放公共 MCP、HTTP 代理或通用数据库查询。

## 结果口径

- 返回实际 from/to、小时或日间隔、总调用/成功/失败/拦截、平均时延和 P95。
- 同一时间桶多个来源合并，最多 31 个时间桶，保留所选时段所有调用，不截断前 50 条来源记录。
- 来源与错误分类分别最多 8 类；`categoriesTruncated` 报告裁剪，趋势与总量不裁剪。
- 意外出现超过 31 桶时失败关闭，不返回“部分数据成功”；集合总数最多 47、字节上限 32768。
- 失败率为 failed / total；拦截和失败可能重叠，不强行让状态计数之和等于总量。
- total=0 时明确无样本，不计算失败率或宣称健康。非正时延值不在文字摘要中解释为真实 0 时延。
- 时延缺失字段由共享序列化省略，Schema 不要求这些可缺失字段；不为了通过校验伪造时延。
- 无操作人、姓名、资源 ID、日志正文、请求参数、堆栈、内部地址或 Trace 明细。

文字摘要提供实际计数、失败率和可用 P95；面板复用所有工具的真实摘要、固定页面导航与
实时菜单过滤，不触发下一次规划或写操作。该能力只读，不创建告警或后台监控。

## 验证及回滚

覆盖 Schema Hash、固定范围、未知身份字段、类型混淆、可信身份、空数据、完整时间桶
跨来源合并、分类裁剪标志、超范围失败、权限撤销无缓存及文字结果真实计数。
真实 PostgreSQL 门禁执行实际 RuntimeLogMapper、领域 Service 与 Adapter，验证另一个租户
及 40 天前记录不进入 30 天结果，计数、P95、趋势相符，敏感字段不越过 Agent 边界。
空库、旧库、validate 和重复迁移均纳入 `P1PostgresMigrationIT`，缺数据库参数直接失败。

新增迁移 `V202610091030`，不改已执行迁移。回滚优先禁用该工具或撤销独立权限，保留历史
迁移及任务审计。代码和数据库门禁不代表逐页面浏览器、真实模型或人工发布门完成。
