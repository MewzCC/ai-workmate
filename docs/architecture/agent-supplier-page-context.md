# 供应商页面的 Agent 上下文与记录定位

本节点接通既有供应商工具与页面选择，不新增工具或开放写入。

## 上下文与结果

- 复用共享页面上下文，只发布实际选中供应商的 supplierId/version、已应用的
  keyword/status/category 和 page/size；未提交搜索文字及列表第一行不代表选择。
- 新建表单没有旧记录身份，关闭编辑或详情即清除选择。联系人、电话、邮箱、
  信用代码、结算条款、风险备注和未保存表单不作为独立上下文字段发送 Planner。
- 服务端页面 Schema 增加数字 version，继续过滤身份、租户及未声明字段。
  页面提示不是授权或乐观锁凭证，领域服务仍重新鉴权并校验状态与版本。
- supplier.createDraft/updateDraft/updateStatus 的成功回执 supplierId 可定位到
  固定 `/oa/suppliers?id=<正安全整数>`；列表查询不猜第一条记录。
  复用已成功任务与实时导航核验，不接受模型结果中的 URL。
- 页面用既有受保护 `GET /api/suppliers/{id}` 读取详情并核对返回 ID；
  非法 ID 不请求，错号/失败不保留旧选择，同 URL 可手工重试。
  预算与供应商复用纯 ID 解析器，不新增路由执行器。

## 生命周期与权限

列表、详情、编辑及认证范围有独立失效序号。关闭、切换对象、卸载以及用户、租户、
权限版本变化后，旧响应不能恢复旧窗口或覆盖新对象。
实时 supplier:manage、列表 canManage 和记录 canManage 共同限制管理入口；
前端提示不代替服务端逐请求授权。

手工更新携带选中版本。失败保留输入与版本，不伪造成功或自动覆盖冲突。
写请求已发送时不声称取消事务，但迟到成功不能关闭新编辑器或改回旧选择；
写后列表使用最新筛选加载函数。状态确认也在确认时检查原详情及认证范围仍有效，
写后仅刷新仍选中的同一详情。新建时清除旧详情，避免关闭表单后把旧对象重新发给 Agent。

## 验证与限制

组件回归覆盖最小上下文、非法及错号 ID、关闭/切换、撤权、乱序响应、新建不继承、
按版本保存、失败保留及写响应迟到；服务端过滤测试证明保留 ID/版本/类别而不保留联系及风险字段。
共享导航测试覆盖三个供应商写回执及页面权限。

无数据库、冻结工具 Schema、Handler、策略或写开关变更；没有绕过 ToolGateway、
单写步骤、确认和独立人工发布门。组件与契约测试不等于真实 LLM/Worker 或浏览器全页面验收。
费用、合同及其他未对接页面继续逐项完成，不能据此宣称全部页面读写已完成。

回滚需一并回退供应商记录映射、详情 URL 读取和版本提示；保留既有领域鉴权、审计与乐观锁。
