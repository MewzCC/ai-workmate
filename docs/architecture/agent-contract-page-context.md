# 合同页面的 Agent 上下文与记录定位

本节点衔接既有合同工具和真实页面选择，不新增工具或开放写开关。

## 页面与成功回执

- 复用共享上下文，仅发布实际选中的 contractId/version、已应用 keyword/status/
  contractType/expiryState 以及 page/size；未提交搜索文字、首行记录和新建表单不代表选中对象。
  责任人、供应商身份、相对方、金额、摘要及付款表单不作为独立页面字段发给 Planner。
- 服务端合同 Context Schema 增加数字 version，未声明字段继续过滤。
  上下文不是权限、租户、确认或乐观锁凭证，领域服务仍重新校验。
- createDraft/updateDraft/updateStatus/updateFulfillment/recordPayment/remind 六个既有
  合同写工具从真实成功回执 contractId 定位固定 `/oa/contracts?id=<正安全整数>`。
  查询不选择第一条结果，也不采用模型提供的 URL。入口仍核验成功任务和当前导航权限。
- 页面复用共享 ID 解析器，调用受认证 `GET /api/contracts/{id}` 并核对返回编号。
  非法 ID 不请求，错号或读取失败清除选择，同 URL 可以手工重试。

## 权限与请求生命周期

实时 contract:manage 与服务端列表/行 canManage 共同控制编辑及业务入口；
状态和履约确认必须命中服务端允许列表，提醒及付款台账必须具有对应行标志。
编辑选项仅在有权打开编辑器时读取，不再在只读浏览时预取责任人与供应商选项。

列表、详情、编辑、选项、付款表单及认证范围分别有请求失效序号。关闭、切换、卸载，
或用户/租户/权限版本变化后，旧响应不恢复旧对象。详情加载期间不发布旧身份。
新建清除旧详情，关闭新建表单不会重新选中旧合同；撤权后的选项响应不会恢复旧选项。

手工保存携带编辑时版本，失败保留输入及原版本。状态、履约、提醒和付款台账登记
复用写后刷新逻辑：加载当前筛选列表，只有原详情仍被选中且认证范围不变时才重读详情，
由真实读取推进版本。确认窗口在实际确认时再次检查详情及认证范围没有失效。
已发出的请求不伪装为取消，但迟到响应不能改回另一条合同或重开已关闭的详情/表单。

普通资料页既有 ACTIVE 编辑入口不因此扩大 Agent 草稿工具状态范围。
付款仅指既有合同台账记录；本节点没有增加实际转账、支付渠道或外部消息能力。
ToolGateway、类型化领域 Port/Adapter、单写步骤、实时权限、确认及人工发布门保持不变。

## 验证与回滚

组件回归覆盖最小上下文、ID 校验、关闭/切换/乱序、撤权、新建、按版本提交、保存冲突、
迟到选项、状态/履约/提醒的写后版本，以及付款台账和迟到业务响应。
服务端过滤测试覆盖版本保留及商务/身份字段剔除；共享导航覆盖六个写回执与页面权限。

无数据库、迁移、冻结工具 Schema、Handler 或写策略变化。回滚需同步撤销合同版本提示、
结果映射和详情 URL 读取，保留领域权限、事务、审计和乐观锁。
组件与契约测试不等于真实模型、Worker 或全页面浏览器验收；其他页面和缺失原子工具继续推进。

2026-10-22 验证：合同组件 26 项、共享导航 13 项及服务端上下文过滤 8 项通过。
默认 OA 全量测试 49 个文件、298 项通过，lint 零错误（3 条既有警告），生产构建通过。
完整后端 mvn test 为 1324 项零失败、零错误，10 项环境依赖测试跳过。
保留既有 AntD/Router 弃用、聊天输入器 NaN 样式和构建大分包提示。

迟到付款台账回归最初假设提交中可点击取消；核对安装版本后确认 Modal 在 confirmLoading
时忽略取消，等待动画不能改变这一行为。未修改组件库或生产取消语义，改为覆盖路由退出
使详情关闭的真实生命周期场景，仍断言迟到请求不重开旧详情、也不发起旧对象重读。
无数据库变化，本轮未重复 PostgreSQL 迁移/重启门禁，未执行真实模型/Worker/全页面浏览器验收。
