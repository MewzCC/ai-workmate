# 资产资料 Agent 工具

## 范围与调用边界

`asset.query` 已提供分页资产资料及版本；本节点新增 `asset.create`、`asset.update`，
不以领用、调拨等生命周期工具代替资料维护。复用现有 `AssetToolPort` 与本地 Adapter，
通过资产领域服务执行；不增加公共 MCP、通用执行、任意 URL 或浏览器模拟操作接口。
Handler 仍只能经进程内 ToolGateway 调用，领域重新解析认证用户的实时业务权限与租户。
未来服务化只替换固定类型的 Adapter，不能扩大工具参数或权限边界。

## 封闭合约

| 工具 | 输入与实际结果 | 策略 |
| --- | --- | --- |
| asset.create | 必填 assetCode/name/category；可选 specification、同租户 departmentId、purchaseDate、originalValue、remark；返回实际 assetId、编码、名称、状态、版本 | 固定创建 IDLE、无人领用、版本 0；不接受状态或保管人 |
| asset.update | 必填 assetId/version；至少一个明确资料字段或 clearPurchaseDate=true；返回真实保存后的最小回执 | 版本条件更新；不接受部门、保管人或状态字段 |

两个工具均为 L1、TENANT_SCOPED、SINGLE_WRITE、NEVER、EXPLICIT，
要求 `asset:write` 及各自 `agent:tool:asset.create/update` 独立权限。
每次结果最多一项、4096 字节，超时 10000ms；不返回人员身份或加载无界操作历史。
新迁移 `V202610211000` 注册两个写工具为 **enabled=false**，不自动打开全局、租户或单工具发布开关。
人工发布、确认令牌、审计、预算、Kill Switch 与单任务一个写步骤限制继续有效。

编码/名称/类别最大长度 64/120/40，规格 120，备注 500。
原值非负、最多两位有效小数，最大 999999999999.99，与 NUMERIC(14,2) 匹配。
购买日期为 ISO 日期；更新版本 0–2147483646，禁止溢出。

更新使用补丁语义：未提供字段保留，可选文本明确空串才清空；
`clearPurchaseDate=true` 明确清除购买日期，不得同时提供 purchaseDate。
改名称不会把历史 NULL 原值改成零。合并发生在当前租户资产行锁内，随后执行版本条件更新。
创建与修改均与业务审计同事务；审计失败回滚业务变化。重复编码不伪装成功。
非幂等写结果不确定时禁止自动重试，应先只读核查，不能用新任务绕过重复写保护。

共享普通页面创建也校验部门租户；普通 HTTP 编辑仍为完整替换语义，
省略原值保持原先归零约定，不改为 Agent 的补丁语义。

## 页面与用户结果

资产页面发布筛选与当前选中资产 ID、版本；编辑或详情关闭后移除选择。
页面上下文仅是规划提示，不是认证或版本依据；缺少确定目标先查询或澄清，禁止猜测 ID。
成功消息包含真实资产名称、编码、状态、版本，并使用现有固定资产页面导航与实时菜单权限过滤。
真实结果摘要不触发新的写任务。删除、批量操作、权限修改及跨域操作不开放。

## 验证与回滚

覆盖封闭 Schema、身份/生命周期字段拒绝、金额边界、缺失字段与明确清空、
版本冲突、单次调用、实际回执、权限收回、跨租户、并发竞争和审计故障回滚。
迁移必须完成真实 PostgreSQL 空库、旧库升级、validate、重复迁移及本地开发库重启检查。
代码及领域集成测试不替代真实模型、Worker、确认交互或全部页面浏览器端到端验收。

回滚优先关闭单工具、撤销独立权限并停止相关任务，保留业务数据与审计。
代码回退时不删除已应用迁移、不修改 checksum；旧计划需要重新规划和授权，不能直调领域。
