# 表单单字段修改工具接入

## 范围与调用链

承接 `92a65482` 的领域能力，新增 `approval.form.patchDraftField`，不是任意页面点击、JSON Patch 或通用 CRUD。
固定链路为 ToolGateway → 类型化单写 Handler → ApprovalConfigurationToolPort → 本地 Adapter → 领域原子命令。
无新增公共 HTTP/MCP/管理员代执行入口，不绕过现有网关、Worker、计划冻结与审计。

输入只有表单编号、预期版本、已有字段 name 和明确提供的 label/required/placeholder/width。
至少提供一项修改；false 和空 placeholder 不能当作缺省。空字符串可清空占位，空对象、null、未知属性拒绝。
不能增删字段、改名、改类型、排序、改变数值限制、发布表单或串联其他写步骤。
领域仍限制 DISABLED、实时 approval:manage、可信租户与 SQL 租户/记录/删除/状态/版本条件。

## 回执与用户结果

内部领域响应改为专用窄 DTO，不再沿用包含原始结构、创建人和无关字段的详情响应。
实际返回 formId/formKey/status/version 和字段当前 name、label、required、placeholder、width。
缺省占位按实际 UI 语义返回空字符串、缺省宽度返回 full、缺省必填返回 false；不补写这些缺省属性。
不额外查询创建人；历史错误的跨租户创建人关联不能被带入新回执。写前校验回执标识避免写后才输出失败。
双语确定性摘要显示真正的字段状态，前端复用已有表单回执定位与当前菜单权限，不采用模型 URL 或猜测首行。

## 授权、版本与迁移

L1、单写、显式确认、禁止自动重试、固定资源范围；仍需独立工具权限和实际表单页权限。
Workspace 只有聊天路由权限不足以取得该工具，必须另有实际业务页权限。
迁移 `V202610240107` 注册独立权限及默认关闭的工具；不改变平台、租户或既有写开关。
代码清单为 138 个工具（40 读、98 写），数量不等于可用/发布/验收通过。
冻结 Hash：`sha256:2d7f9c12e2c7bc7a72f986c077ba8de9a5b81f69d23342f1e8408959f8369744`。
迁移与真实 Bean 比较 Schema 树和冻结 Hash，不对 PostgreSQL jsonb 调整属性顺序后的字符串重新计算代码 Hash。

Ruling: 使用窄 DTO 替代旧内部详情响应——写结果不需要整份 Schema 或创建人资料；代价是旧内部调用方需同步类型，普通表单 HTTP API 不变。
Ruling: 继续要求预期版本与已有字段名——不让模型从查询结果递归生成新写计划；Workspace 缺少实际对象时仍需用户选定/补充，不声称所有任意请求均可直接执行。
