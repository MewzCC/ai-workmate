# Agent 浏览器只读执行与小窗持续性

目标是验证用户发起查询后能看到真实结果、定位业务页面，并在切页后保留小窗内容。
上一节点已通过实际模型的 HTTP 意图、规划与执行测试，本节点继续验证 Chromium 中的真实 OA 页面，不拦截或伪造 API。

发现小窗只生成计划，需要再点执行；本节点让当前页面支持的 L0/NONE/NONE 工具自动执行一次。
L1/L2、需要确认、能力不一致、未知工具和已离开源页面的计划都不能自动执行。
沿用原 execute、事件订阅和结果加载路径，不增加工具入口，不改变 ToolGateway 或写开关。
计划请求在组件卸载后失效，防止权限快照重建布局后迟到响应触发执行。
另记录源页面代次：离开后即使返回，原请求也失去自动执行资格，保留计划供用户手动执行。
失败保留明确错误，不自动循环重试。

真实浏览器测试通过独立后端、数据库、Redis 和最小权限账号，加载实际 Vite 应用。
只在本机随机端口运行，浏览器进程不继承模型或数据库凭据，仅携带独立测试登录签发的内存 Cookie。
模型配置和显式外呼开关与已有验收复用。浏览器验证小窗查询、实际待办文字、自动跳转、清空已发送输入、
切页保留结果与未发送草稿；Workspace 验证真实通知文字、输入清空及受控业务链接。
不把 Workspace 的链接点击表述为自动导航，不把两个读工具表述为全页面或写能力验收。

执行步骤为浏览器复现缺口、定向失败测试、最小修复、定向与真实浏览器重验、全量门槛、独立审查和中文提交。
默认离线测试不启动浏览器或外呼模型，显式运行：

```powershell
./scripts/verify-agent-live-model.ps1 -EnableLiveModel -Browser
```

本机测试环境变量条件与[真实模型只读验收](agent-live-model-read-acceptance.md)一致。
截图只包含隔离合成数据，保存在本地 `output/playwright/agent-read-browser`，不提交；日志只输出阶段和状态摘要。
本节点不新增迁移、权限、工具或依赖，完整目标仍需其他页面、普通聊天和人工确认写执行验收。

## 2026-10-25 已取得证据

- 原小窗定向用例先失败：发送后 execute 调用为零；真实浏览器同时复现 plan 200、没有 execute，等待结果超时。
- 最小修复后定向通过；独立审查发现 A→B→A 的迟到竞态，新增用例先复现错误自动执行，再以页面代次修复。
  最终小窗定向 26 项通过，包含风险、工具元数据、源页面变化、卸载、执行失败及 L1/L2 确认。
- 实际 Chromium 验收 1 项零失败、零错误、零跳过。小窗读取真实待办、自动导航、清空输入，
  切页保留对话/结果/未发送草稿；Workspace 读取真实通知并通过授权链接进入消息页，页面脚本错误为零。
  服务器进一步核对该账号恰好两项成功任务和两次成功工具调用，租户写开关仍为 false。
- 共享真实模型配置提取后，原 HTTP 模型验收再次 2 项零失败、零错误、零跳过，四次实际响应均为 JSON。
- 浏览器脚本前置错误分别为 Windows ESM 路径、Vite 模块入口、工作目录导致 Tailwind 配置未加载；
  它们不计为业务回归证据。修正后实际 OA 样式请求 200。关闭按钮定位同时匹配 AntD 中英文，未改产品关闭行为。
- 浏览器正常退出时由脚本关闭 Chromium 与 Vite；超时只终止捕获的自有子进程，并有界等待确认退出。
  Node 清理使用嵌套 finally，避免浏览器关闭异常跳过 Vite 清理。
- 最终 OA 全量 54 个文件、427 项全部通过，包含本次新增的 12 项边界回归。
  lint 零错误、3 条既有 Hook 警告；生产构建通过，仍有既有包体积提示。
- 最终 Java 17 `mvn clean test` 为 1486 项、零失败、零错误；HTTP 7 项和 Worker 8 项实际执行、零跳过。
  2 项既有环境跳过为 Docker 不可用的初始化测试和未配置观测数据库的日志聚合测试。
  上述显式真实模型 2 项与浏览器 1 项独立计数，不合并进默认离线全量。
- 临时数据库、Redis 子进程及浏览器驱动进程均无残留；开发库仍为 162 条迁移、版本 `202610242252`。

## 回滚与后续

回退对应提交可恢复小窗手动执行只读计划，无数据库回滚步骤；写确认与网关校验不受影响。
本节点只有 1440×900 的功能验收，不代表全部桌面/移动布局或全页面工具验收。
浏览器继续发现的安全与功能项应独立处理；例如既有 CorsConfig 仍使用任意 Origin Pattern，
不能把本次同源代理验证表述为可信 Origin 白名单或完整 CORS 安全验收。
本节点发现的小窗本地“假取消”由后续[真实取消节点](agent-task-cancellation-ui.md)处理；
原始只读验收不作为取消流程完成的证据。
