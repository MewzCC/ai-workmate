# 表单字段定义只读工具

## 目标与调用链

新增 `approval.form.definition.query`，补齐配置摘要无法回答具体字段的问题。
输入只有 `formId`；成功返回实际编号、标识、名称、状态、版本及受控字段列表，
不返回原始 Schema、说明、身份、创建人、申请数据或内部存储内容。

固定链路：ToolGateway → `TypedReadToolHandler` → `ApprovalConfigurationToolPort` →
本地 Adapter → `ApprovalEngineService.readFormDefinitionAgent`。不开放公共工具/MCP/HTTP 调用入口。
Handler 不持有 Mapper；领域端口不携带传输地址，后续可替换固定服务目标的远程 Adapter。

## 授权与边界

- L0、无副作用、安全只读重试、无写确认；仍受平台、租户、独立工具权限、限流和审计门禁。
- 领域实时检查 `approval:read`，并核对实时租户与 Gateway 可信租户；用户所属租户变化时拒绝旧调用。
- 生产查询同时包含租户、记录 ID 和未删除条件，不先按 ID 取出再判断租户。
- 只绑定表单管理页；Workspace 还需实际表单页路由权限，只有聊天入口不能取得该工具。
- 定义原文最多 64 KiB，字段最多 20、选项最多 10，类型、名称、标签、占位和宽度沿用封闭语义契约。
- 未知根属性、脚本等字段扩展、空或超限定义拒绝，不默默删掉扩展后当作完整结构返回。

兼容决策来自实际种子，而非放宽任意结构：仓库六份模板省略了部分默认值，费用模板含数值下限。
读取时仅补充 `required=false/options=[]/width=full`，旧 `key` 转为业务 `name`，同时存在且冲突时拒绝。
只读字段另含可选数值 `min`（仅 number/money，范围 ±10^15）；其他未知扩展继续拒绝。
不修改数据库 Schema 原文，不放宽原 Agent 发布校验；设计器普通保存同时保留已有数值下限。
读取专用解析器使用精确十进制，避免超出边界的小数被舍入为边界值，并保留历史约束的小数精度。
设计器仍使用 JavaScript 数值；本节点不宣称超过该数值精度的约束可以经 UI 无损往返。

只读输出复用已冻结的写入语义字段 Schema；发布校验函数只增加返回值供领域复用，不放宽原发布验证。
这不是可执行的 JSON Schema、脚本、URL 代理或任意查询。返回的名称和标签仍是不可信文本。

## 结果与数据升级

摘要不送回 Planner 产生新步骤。成功任务使用实际 `formId` 进入已受保护的表单详情，
侧边面板与 Workspace 共用固定导航解析器，不使用输出 URL 或模型参数。

该迁移已在隔离验证库执行，保持不变；后续数值下限兼容通过 `V202610231830` 前向升级输出契约。

除上述已知兼容外，不符合语义契约的历史定义需人工核对，工具不批量迁移历史 Schema 或申请快照。
当前只增加读取；依据查询结果动态生成写步骤、后台自循环或同任务多写仍禁止。
后续自然语言局部编辑应是独立评审的原子领域命令，在领域内确定性保留未修改字段，不能借本工具绕过计划冻结。
既有 Agent 全量字段更新契约不承载 min，本节点没有启用该写工具或把读取完成当成约束安全编辑已完成。
真实模型、所有页面浏览器与人工写发布门仍未完成。

回滚先按既有管理流程停用此工具，再同步回退定义、Handler、Port/Adapter、页面绑定及结果导航；
保留已执行迁移和权限数据，不删除 Schema History，不回退其他写工具安全策略。
