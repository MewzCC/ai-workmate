# 本人驾驶舱聚合查询工具

## 目标与契约

`dashboard.overview.query` 补齐驾驶舱的真实聚合读取，而不是仅绑定待办查询。
输入为可选 `days`，范围 1–30，默认 7；不接受用户、租户、权限或任意查询表达式。
工具为 L0 / SELF / NONE / READ_ONLY_SAFE，要求实时 `dashboard:read` 与独立
`agent:tool:dashboard.overview.query` 权限，绑定驾驶舱及全局 AI 工作空间。

Handler → `DashboardToolPort` → 本地 Adapter → 既有 `DashboardService.overview`。
领域重新解析有效用户，并使用实时租户和本人 ID 查询。未来远程化仅替换固定服务
Adapter，不改变 Gateway、冻结 Schema、页面目录或领域授权语义。

返回生成时间、时段、最多 4 项当前所选指标、30 个日趋势点及前 16 类业务分布。
`distributionTruncated` 明确说明分布裁剪，不把局部结果当全量。总集合条数最多 50，
字节上限 32768。不返回待办姓名、申请标题、资源 ID、审计摘要或租户汇总。
日期范围影响趋势与分布；指标计数仍与页面一致，是当前总量，不是假装时段计数。

## 结果与导航

服务端生成双语指标值及所选时段申请提交/完成数摘要，不使用 Mock 或数组条数替代指标。
侧边 AI 操作面板将成功步骤摘要追加到对话，并从固定工具目标页面表解析导航。
此逻辑适用于所有已有工具，不再仅特判待办；导航最终仍由布局实时菜单权限过滤。
查询失败或部分失败不自动跳页，已有带筛选条件的待办查询不跳到不匹配的默认列表。
工具结果中的字符串不能成为 URL，结果不触发新的规划或工具执行。
