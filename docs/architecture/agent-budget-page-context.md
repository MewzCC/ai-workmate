# 预算页面的 Agent 上下文与记录定位

预算已有查询、草稿创建/修改/启用/取消工具，但页面原先没有发布选中记录和版本，
成功回执也只能打开模块首页。本节点补齐这一纵向切片，不新增工具或开放写入。

## 页面提示字段

复用 `usePublishPageAgentContext`，只发布当前实际对象的 budgetId/version、
已应用的 keyword/status/fiscalYear，以及列表 page/size。
没有选择时不猜第一行，新建表单没有旧记录身份，新详情加载期间不发布旧对象。
负责人身份、金额、余额、说明、表单草稿、角色、租户和权限不进入提示。
服务端预算 Context Schema 接受数字 version，未知字段仍过滤。

上下文不是授权或版本凭证；工具参数仍受冻结 Schema、单写步骤、人工确认、
ToolGateway、实时权限、租户归属和领域乐观锁复核。工具 Schema/Handler 和写开关未改变。
手工额度占用/释放/支出入口不因此成为 Agent 工具，不能绕过永久禁止项。

## 结果与生命周期

- 四个预算写工具的真实回执 budgetId 可进入固定 `/oa/budget?id=<正安全整数>`。
  共享解析器先校验导航，页面调用既有受认证 `GET /api/budgets/{id}` 并核对返回 ID；
  不从列表、模型参数、摘要或结果 URL 猜对象，URL 不授予权限。
- 列表、详情和编辑选项分别使用失效序号；关闭、切换、卸载及用户/租户/权限变化后，
  迟到结果不能恢复旧对象。同 URL 详情失败后允许手工重试。
- 实时 budget:manage 与服务端 canManage 同时成立才可管理，旧行标志不能代替当前权限。
- 表单校验期间目标变化不继续提交；已发送的操作不伪装取消，但迟到结果不恢复旧窗口。
- 手工成功修改后，仅刷新仍被选中的原详情版本，避免继续向 Agent 提示旧版本。

## 验证与回滚

覆盖最小上下文、真实版本、非法/错号 ID、关闭/切换/撤权、乱序响应、旧管理标志、
选项读取期间撤权、按版本提交、写后刷新及失败重试。服务端测试保留预算 ID/版本/年度，
丢弃负责人身份、租户和金额。组件测试不代替真实模型、Worker 或浏览器端到端。

无数据库和迁移变更；回滚需同时回退预算记录映射、URL 读取及版本提示，保留领域授权、
乐观锁和审计。费用、合同、供应商等页面的上下文仍须继续，不属于本节点已交付范围。

验证资源说明：新增 AntD 页面回归后，默认机器规模并发的两次全量执行均出现既有资产页
认证后操作按钮的等待失败，而资产/预算定向组合通过。保持全部断言、默认超时和测试范围，
仅将并发收敛为 1–2 个 worker 后，46 个文件、229 项全量测试通过。
