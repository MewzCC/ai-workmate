# 会议室资料 Agent 工具

## 目标与分层

新增 `meeting.room.query`、`meeting.room.create`、`meeting.room.update`，补齐会议室资料查询与维护，
不把 `meeting.query`、预约或取消工具当作基础资料操作，不修改已有工具冻结 Schema。

固定 Handler → `MeetingRoomToolPort` → 本地 Adapter → `AdminAssetsService`；未来服务化替换 Adapter，
不改变任务、封闭参数、确认或网关。不存在公共 MCP、任意 URL、通用执行或模拟点击接口。
所有执行仍经持久任务和进程内 Tool Gateway；领域按认证用户重新解析实时权限与租户。

## 合约

| 工具 | 输入与结果 | 安全策略 |
| --- | --- | --- |
| meeting.room.query | keyword/status、page 1–10000、size 1–50，返回真实资料、版本、总量和分页；按创建时间及 ID 稳定排序 | L0、TENANT_SCOPED、NONE、READ_ONLY_SAFE；业务权限为 assets:read 或 meeting:read:self，独立 Agent 权限仍必须满足 |
| meeting.room.create | 必须提供 code/name/capacity/status，可选 location/facilities/remark；返回实际 roomId、编码、名称、状态和版本 0 | L1、TENANT_SCOPED、SINGLE_WRITE、NEVER、EXPLICIT；需要 meeting:write 和独立 Agent 权限；数据库工具默认关闭 |
| meeting.room.update | 必须提供 roomId、version，至少一个资料字段；返回实际编号、名称、状态及新版本 | 同创建策略；仅单资源、按版本更新，数据库工具默认关闭 |

编码/名称最长 64/120 字符，位置/设施各 200，备注 500；写入容量 0–10000，状态 OPEN/CLOSED。
查询不额外限制历史合法容量上界，不返回人员身份、预约正文、权限目录或任何内部存储路径。
查询每次最多 50 项、262144 字节；写入回执上限 4096 字节。

修改采用补丁语义：未提供字段保持不变；可选文本显式提供空串表示清空。禁止无字段修改，
编码和名称不能清空。领域在当前租户会议室行锁内合并字段，复用版本条件更新及同事务业务审计。
关停继续检查有效预约并与预约使用共享行锁。过期版本、非法状态、重复编码和审计故障失败关闭。
创建不是业务幂等工具：编码唯一约束防止重复记录，但结果未知时不能自动重试，也不把编码冲突伪装成功。

## 页面、结果与权限

会议室与 AI Workspace 使用现有能力目录；成功结果采用固定会议室页面导航，仍按实时菜单过滤。
文字结果包含真实名称、编号、容量或保存状态及版本，不只有成功标记。长列表有界显示，结构化分页结果保留。
只有编辑弹窗打开时，页面上下文才包含该会议室 roomId/version；关闭后清除选择。上下文仍是不可信提示，不能替代资源、权限或版本校验。

独立权限：`agent:tool:meeting.room.query`、`agent:tool:meeting.room.create`、`agent:tool:meeting.room.update`。
新增 `V202610201230`，不修改历史迁移。权限目录沿用默认租户种子，角色独立工具权限按已有相应业务权限继承；
运行时仍同时复核独立工具权限、业务权限及租户。只读工具注册默认启用；两个写工具注册默认关闭，全局与租户写开关、
确认令牌、预算和独立人工发布门仍有效，不由开发 Agent 自动启用。

缺少确定目标或版本时应继续查询/澄清，不能猜测目标、以当前时间替代版本，或使用查询结果触发后台写入链路。
本阶段仍是一个任务最多一个写步骤；删除、批量修改、外部消息和配置扩权不开放。

## 验证与回滚

验证包括封闭 Schema、未知身份字段拒绝、分页边界、ANY 读取权限、默认关闭写工具、一次领域调用、
缺失字段保留、明确清空、实际版本、重复编码拒绝、权限撤销、跨租户和审计失败回滚。
真实 PostgreSQL 验证领域与 Adapter，不代替真实模型、Worker、确认令牌及逐页浏览器端到端验收。
本里程碑的完整验证结果在全页面工具交付清单记录；工具登记数量不是已运行成功数量。

回滚优先关闭对应工具或撤销独立工具权限，并保留审计。应用回退时应停止相关任务并重新规划，
保留 Flyway 与版本列，不删历史或修改 checksum；旧计划不得绕过工具禁用和代码清单校验。
