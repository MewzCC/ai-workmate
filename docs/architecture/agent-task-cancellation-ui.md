# Agent 小窗真实取消

上一节点为已提交的真实模型与浏览器只读闭环，本节点继续修复小窗“取消计划”只清理本地状态的问题。
取消必须调用已有本人任务接口，以实际 CANCELLED 回执为准，保留对话、计划、已有结果和未发送输入。
服务端只允许 PLAN_READY、WAITING_CONFIRMATION、QUEUED，拒绝 RUNNING 和终态；前端不放宽状态机，也不承诺回滚已完成操作。

共用取消状态判断与请求协调器供小窗和任务中心调用，避免各自把 HTTP 成功或错误后的本地状态当作真实取消。
一个用户动作只发一次 POST；冲突或网络错误可以安全查询一次实际状态，不自动重发取消。
认证、授权或资源归属拒绝不继续查询；未取消则保留任务，已开始/结束则显示真实状态，未知或错误回执失败关闭。
小窗请求期间阻止重复取消、确认执行和新计划；权限变化导致卸载或任务切换后迟到响应失效。
规划、确认/入队、取消、结果和事件流各自记录请求代次，取消后的旧 202、旧确认响应或已投递 SSE 回调不能恢复旧任务或覆盖新计划。
来自 SSE 的终态不能被较旧的核实读取降回运行态；核实成功与 SSE 成功共用去重后的页面刷新通知。

本节点验证定向 RED→GREEN、真实 Cookie 取消、跨用户/租户拒绝、取消后的执行拒绝和已运行任务不能取消。
沿用真实数据库与 Redis 隔离；运行态拒绝通过独立库的短暂通知表锁等待真实 Worker 进入 RUNNING，不模拟 Handler。
所有产品及写工具开关不变，不新增接口、迁移、工具或依赖。最后通过前后端全量门槛后独立中文提交。

## 定向证据

- 原小窗用例先复现取消 API 调用为零，随后接入真实接口；定向测试覆盖等待确认、失败保留、显式重试和实际完成结果。
- 旧 RUNNING 核实覆盖 SSE 成功的用例先失败，再通过终态保护修复。
- 独立审查发现核实成功漏刷新及迟到 202 串任务；三个新增断言先失败，再以一次性刷新和执行代次修复。
  已投递旧 SSE 回调也有先失败后通过用例。另复现小窗卸载后残留 Modal 仍签发凭证的问题，
  Modal 现在检查所属计划代次；已发出的确认请求在卸载后返回也不会执行。
  最终前端定向 55 项通过，含小窗 37、协调器 14、任务中心 4。
- 真实 Cookie HTTP 与服务测试 21 项零失败、零错误、零跳过：HTTP 10 项覆盖原链路和新取消场景，服务单测 11 项。
  隔离库短暂表锁使真实 Worker 保持 RUNNING，此时取消返回 409；释放锁后正常完成，再取消仍返回 409。
  跨用户、跨租户、匿名和无效 Cookie 请求均被拒绝；取消 PLAN_READY/QUEUED 后不能再执行，且没有工具调用。
- 最终源代码的真实浏览器验收 1 项零失败、零错误、零跳过。既有模型读取、跳页和小窗持续性通过，
  新增任务中心确认取消实际调用本人接口，列表显示 CANCELLED；服务端进一步确认该夹具任务取消且工具调用数为零。
  此任务由 L0 冻结夹具预置，不把它当作真实模型生成的取消计划；没有发布 Agent 写工具。
- 全量门槛首次发现字典编辑用例在受保护详情预填完成前修改字段，导致最终请求带初始名称。
  `resetFields` 会重建输入节点，原用例操作了旧节点。用例改为先等待初始名称和可用保存按钮，
  再重新获取当前输入框操作；原版本 7 与输入保留断言不变，不改字典业务代码。
- 修正后字典定向 24 项通过；最终 OA 全量 55 个文件、453 项全部通过，无跳过。
- 严格构建另发现新协调器测试夹具字段不完整；补齐完整 `AgentTaskDetail` 后定向 14 项通过，未使用宽松类型断言。
- 最终 lint 零错误、3 条既有 Hook 警告，生产构建通过且保留既有包体积提示。
- Java 17 `mvn clean test` 为 1489 项、零失败、零错误，真实 HTTP 10 项与 Worker 8 项均零跳过执行。
  2 项既有环境依赖跳过为 Docker 不可用的初始化测试，以及未配置观测数据库的日志聚合测试。
  显式真实浏览器验收单独计数，不混入默认离线全量。
- 补齐测试 DTO 后再次完整运行 OA：55 个文件、453 项全部通过；最终没有失败测试进入提交。
  自建数据库、Redis 与浏览器驱动进程均无残留，开发库仍为 162 条迁移、版本 `202610242252`。

## 边界与回滚

没有实现中断 RUNNING、回滚业务效果或批量取消。任务中心的既有 Modal 保留，其余列表/详情生命周期不在本节点重构。
回退对应提交会恢复小窗本地清理的旧行为，应避免将其当作真实取消继续使用；无数据库回滚步骤。
完整目标仍需可信 Origin 白名单、普通聊天、其余页面和人工写能力发布验收。
