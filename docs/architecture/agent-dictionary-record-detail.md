# 字典 Agent 精确定位的受保护详情前置能力

## 本节点范围

全页面 Agent 的目标是“定位对象—受控工具调用—具体结果—真实页面定位”，不是仅查询待办。
字典为类型与字典项两级资源；既有工具回执分别携带类型 ID 或字典项 ID，不能依赖当前列表第一页、
相同编码或前端猜测来恢复对象和乐观锁版本。本节点先补单记录读取与客户端，不宣称字典页面闭环完成。

新增接口均使用 JWT 认证身份、实时 `route:dictionary` 与 `Result<T>`：

| 接口 | 返回内容 |
| --- | --- |
| `GET /api/admin/dictionaries/{id}` | 既有 `DictionaryTypeResponse`，含实际版本与可管理标志 |
| `GET /api/admin/dictionaries/items/{itemId}` | `DictionaryItemDetailResponse`，含 `dictionaryType` 与 `item`，各自保留实际版本 |

仅返回既有安全 DTO 字段，不返回身份、内部配置或存储地址。查询参数不能替换认证用户或租户。
类型、字典项及其父类型均限定当前租户与未删除；资源不存在、跨租户或父类型已删除统一 404。
停用但未删除的记录仍可供有读取权限的用户查看，不因管理权限缺失而扩大权限或隐去状态。
管理与删除标志继续由实时权限、引用计数等既有领域逻辑计算；只读用户不能据此获得写能力。

编号必须为正整数；参数约束走中英文消息源。非数字或超出 Long 范围的编号由全局参数转换异常映射
返回统一 400，而非 500，不回显底层异常。服务层仍重复校验编号和读取权限。
前端 `dictionaryApi.typeDetail/itemDetail` 复用既有 Cookie、语言和错误处理请求封装。

## 边界与后续

- 不新增 Agent 工具、权限码、数据库迁移或写开关；工具总数维持 136。
- 不让模型访问任意 HTTP；未来工具执行仍必须经 ToolGateway 和领域服务鉴权。
- 本节点不接通字典页选中上下文、工具回执跳转或写后刷新；后续须区分类型/字典项身份，
  用受保护详情定位真实父级，并验证撤权、乱序响应和版本变化。
- 不把前端上下文或工具回执版本当作授权依据；禁止能力与人工发布门保持原样。

## 验证与回滚

定向门禁覆盖认证、实时撤权、只读用户、非法编号、国际化、父子版本与客户端路径。
`DictionaryDetailPostgresVerifier` 在 P1 随机测试 Schema 中使用实际 Mapper 和 PostgreSQL 查询，
覆盖双向跨租户、删除父级/子项、引用计数、权限变化与版本未改写；访问身份和审计依赖采用测试替身。
不声称该验证等同真实 JWT、模型、Worker 或浏览器端到端验收。

没有结构变化，不需要升级或回退开发数据库；P1 使用既有完整迁移门禁，不操作生产库。
回滚同步回退接口、DTO、客户端及测试；后续页面若已依赖这些接口，应先回退调用方。
全局参数转换的 400 映射影响相同类型的非法路径/请求参数，属于预期客户端错误处理修正。
