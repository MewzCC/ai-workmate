# 规则单条件值修改工具

## 用户能力与调用边界

`approval.rule.patchDraftCondition` 将已交付的单条件值领域命令接入固定 Gateway 工具目录。
用户明确指定一个禁用规则、实际版本、条件编号及新值后，只修改该条件值。
不得自行猜测条件位置，不允许基于工具输出递归规划；缺少必要目标时继续澄清。

Handler 复用 `TypedWriteToolHandler`，通过 `ApprovalConfigurationToolPort` 的类型化命令和回执
调用本地领域 Adapter；不会让 Controller、Planner 或 Worker 持有 Handler。
未来服务拆分只替换受认证、固定目标的领域 Adapter，不把 JSON 路径、URL 或租户身份变成工具参数。

领域鉴权、精确数值/布尔类型保持、原始动作保留和事务审计的设计及真实数据库验证见
[规则条件局部修改领域命令](agent-rule-condition-patch.md)。本工具不修改字段、运算符、
组合逻辑或动作，不启用规则，不接收完整定义，不合并多个写步骤。

## 冻结契约

- 输入封闭为 `ruleId/version/conditionNumber/value`；编号从 1 起，最多 10。
- 版本范围 1 至 2147483646，值为 1 至 120 字符的非空白文本；Handler 保留原始字面值。
- 不接受身份、权限、租户、状态、动作、原始 JSON、脚本或 URL 目标参数。
- 回执封闭为规则 ID、新版本、禁用状态、条件编号、字段、运算符和实际值七个属性。
- Schema Hash：`sha256:588a77eb3294d8955af4c31a203a16303a7c37f8ab54165375ef9403bf994b24`。
- L1、SINGLE_WRITE、EXPLICIT、NEVER、FIXED_RESOURCE；最多一条结果、4096 字节、15 秒。
- 实时业务权限 `approval:manage` 与独立 `agent:tool:approval.rule.patchDraftCondition` 均必须具备。
- 仅绑定审批规则页面；Workspace 入口还须同时具有 Workspace 和审批规则页面权限。
- 工具种子默认关闭。权限绑定只从具有管理权限的既有角色派生，不改变全局/租户执行或写开关。

中文及英文结果显示实际条件编号、新版本、值，并明确规则仍未启用。工具摘要按纯文本渲染，
保留条件字面内容，不截断成另一个阈值，也不把其中的链接或 Markdown 当作操作。
成功回执只从实际 `ruleId` 定位现有规则页面，继续通过最新菜单权限过滤，不使用模型 URL 或列表首行。
