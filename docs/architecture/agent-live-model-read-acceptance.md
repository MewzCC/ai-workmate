# Agent 真实模型只读规划与执行验收

## 本次范围

`AgentLiveModelHttpIT` 使用已有服务端模型配置，实际执行中文意图识别和结构化规划，随后通过真实 Cookie、Controller、Worker、ToolGateway 和领域 Service 读取数据库。
同时提供 `notification.mine` 与 `todo.query` 两个有权限工具，验证模型根据“请帮我查询我的通知。”和“查一下我的待办。”选择正确工具。
没有冻结计划、模型响应夹具或模拟 Handler。通知随机标记、待办申请编号及申请人来自每次新建的隔离数据库，结果必须逐项匹配，并排除另一用户的记录。

共享 `AgentHttpTestFixture` 统一真实密码登录、最小权限用户和回环 HTTP 请求；共享 `LeaveReadFixture` 统一待办业务夹具。
原有 HTTP 和 Worker 回归继续使用这些夹具，避免重复维护认证和业务关联 SQL。
测试观察器仅透明委托实际模型客户端，记录耗时、响应字符数、粗粒度格式和异常类型，不改写结果，不记录提示词、响应正文或凭据。

## 边界

- 每类测试独立创建临时数据库及 Redis 进程，先关闭 Spring 消费者和连接池，再清理所持有资源。
- 只在测试上下文启用 L0 规划与执行，全部写开关保持关闭，不修改产品或开发库配置。
- 不增加工具、接口或迁移；目录仍为 140 个工具（41 读、99 写），不代表全部已启用或验收。
- 实际意图和规划预算不变；规划 HTTP 客户端单次等待 40 秒，只容纳既有规划与一次解析重试，不提高 Agent 运行上限。
- 外部模型测试使用 `IT` 后缀，普通 `mvn clean test` 不外呼模型。显式执行缺少授权标记或配置时失败，不静默跳过。
- 本次只证明两项只读能力，不证明浏览器结果展示、自动导航、普通聊天、其他页面工具或人工确认写执行。

## 运行

需要 Java 17、Maven，以及[隔离集成环境](agent-persistence-integration-isolation.md)要求的本机 PostgreSQL 和原生 Redis 可执行文件。
通过本机测试环境变量提供数据库配置，通过服务端环境变量提供 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`。
脚本也可从本地服务端 `.env` 仅读取上述三个模型配置；已有进程环境变量优先，不读取数据库或迁移设置。
不要向命令参数、文档或聊天粘贴实际凭据。

```powershell
./scripts/verify-agent-live-model.ps1 -EnableLiveModel
```

脚本只在子进程环境中传递凭据，退出时恢复修改的环境变量；控制台仅输出白名单测试摘要和本地日志位置。
测试禁用应用及模型日志，既有隔离环境的子日志级别也显式覆盖，避免父级关闭后仍输出内部记录。
私有日志留在系统临时目录，不提交到 Git；排错时只提取必要且脱敏的摘要。

## 已获得的证据

2026-10-25 最终真实模型测试为 2 项、零失败、零错误、零跳过；四次模型响应均为 JSON 对象，耗时分别约 1.48、1.66、0.87、1.26 秒。
两个自然语言请求分别生成正确的单步 L0 计划，执行前无结果和调用审计，真实执行后各有一次成功调用，返回本人实际记录及非空摘要。
日志级别修正后的私有日志没有应用日志行。未提供 `-EnableLiveModel` 的脚本调用在加载配置和创建资源前被拒绝。

最终 OA 默认全量为 54 个文件、415 项全部通过，未删除或跳过测试。
lint 零错误、3 条既有 Hook 警告，构建通过并保留既有包体积提示。
Java 17 `mvn clean test` 为 1486 项、零失败、零错误；HTTP 7 项和 Worker 8 项均实际执行、零跳过。
2 项既有环境依赖跳过分别为 Docker 不可用的 `InitSqlIntegrationTest` 和未配置观测数据库的 `RuntimeLogMapperPostgresIntegrationTest`。
显式真实模型 2 项独立于上述离线全量，不混入该数量。
结束后自建临时数据库和 Redis 子进程均为零，开发库维持 162 条迁移、版本 `202610242252`。

前端门槛首次出现表单迟到写回归超时；原整文件单独运行 20 项通过，该多步用例耗时 4.85 秒。
单 worker 运行又出现合同迟到保存用例耗时 6.29 秒，超过默认 5 秒测试完成预算。
因此将 OA Vitest 单项完成预算设为 10 秒，不修改断言、断言级等待或业务代码；最终必须重新通过全量测试。
独立只读复核确认这项预算调整无阻断问题，代价是挂起测试最多延后约 5 秒报告失败。
