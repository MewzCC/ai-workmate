# 接口联调中心的 Agent 选中对象与版本

## 范围与影响面

复用 `usePublishPageAgentContext`、`usePermission`、`parseRecordId` 和共享成功结果导航，
将既有端点元数据工具与 `/oa/api-center` 页面接通，不新增工具、HTTP 执行能力或写开关。
不改变业务接口、数据库、历史迁移、冻结工具 Schema、Handler 或 ToolGateway。

页面只发布实际选中 `endpointId/version`、已应用 `keyword/status/page/size`。
没有选择时不猜第一行；正在输入的搜索文字、编辑草稿、上游配置、相对路径、
请求模板、响应预览和认证身份不进入上下文。服务端固定页面白名单增加数字 `version`，
它只是规划提示，不是授权或可信并发凭据。

`integration.endpoint.createDraft/updateDraft/updateStatus` 仅从成功回执 `endpointId`
取得记录身份。与其他模块共用成功任务和实时导航核验，构造固定
`/oa/api-center?id=<正安全整数>`；查询结果不取列表第一项，不接受工具输出 URL。
浏览器再调用原受保护详情接口，要求返回 ID 匹配；服务端仍负责租户及资源授权。

## 页面操作约束

- 实时 `route:api-center` 决定是否读取业务数据。管理和人工执行分别要求
  `integration:endpoint:manage`、`integration:endpoint:execute`，再与服务端页面/行标志取交集。
  不从前端角色推断权限，不因旧列表标志继续暴露操作。
- 编辑前并行读取选项与受保护详情，用实际详情版本保存；已变为 ACTIVE、ID 不匹配或
  不再可管理时拒绝进入编辑。新建没有前一条详情的身份。
- 列表、详情和编辑各有请求序号；认证用户、租户或权限快照变化后清空旧数据并失效请求。
  关闭、换对象和卸载后，迟到详情/选项不恢复旧抽屉或上下文。
- 保存失败保留输入和预期版本；成功只关闭仍对应本次保存的编辑窗口。
- 状态与人工沙箱联调复用确认及写后刷新。确认前后核验当前作用域和选中请求；
  执行中的写请求不被假装取消，但迟到响应不能覆盖新选择。
  刷新使用当前筛选，且只重读仍选中的相同详情，发布其真实新版本。
- 页面持有本页确认弹窗的销毁句柄，关闭、切换、撤权及页面卸载主动清理，
  不在持久 App Provider 中留下旧端点名称。迟到写反馈同样核验原选择；
  已过期错误不弹消息、不保留可误重试的旧确认。

人工沙箱联调不等于 Agent 工具：本节点不让模型执行网络请求，不允许任意上游或 URL。
既有人工接口仍由后端权限、版本、固定上游白名单及安全校验保护。

## 验证、发布与回滚

组件门禁覆盖最小上下文、无选择、非法路由 ID、错号详情、关闭/乱序、撤权、
新建、受保护编辑版本、失败保留输入、迟到选项、过期确认及写后新版本/新选择。
共享导航覆盖三种写回执；服务端上下文过滤验证路径、模板、响应及身份被移除。

前后端建议同版本发布；只升级前端时，旧后端会移除未知 `version` 提示，
不能据此绕过版本校验。回滚同步回退页面逻辑、服务端提示字段和回执映射，
不修改数据或撤销既有服务端鉴权。无迁移，不需要数据库回退。
本节点测试不等于真实模型、Worker 与全页面浏览器验收；总工具数量仍为 136。

2026-10-23 验证：接口页 24 项、共享导航 14 项、服务端上下文过滤 9 项定向门禁通过。
反向测试先复现版本提示被移除、回执无法定位、迟到成功提示和撤权后残留确认，随后修复。
独立只读审查的两项反馈已修复并复核通过；Java 17 `mvn clean test` 1339 项零失败、
零错误，10 项环境依赖测试跳过。OA lint 零错误（3 条既有警告），50 个文件 323 项全量测试
及生产构建通过。
无数据库或迁移变化，本节点未重复 PostgreSQL 迁移/重启验证；不以此前数据库门禁代替本轮端到端。
保留既有 AntD/Router 弃用提示、聊天输入器 NaN 样式及大分包提示。
