# 普通聊天与受控业务查询的连续会话

本节点继续全页面 Agent 目标，验证普通聊天、真实工具结果与会话上下文可以连续使用。
既有只读浏览器验收没有覆盖普通聊天；新增真实场景复现未选择知识库的问候返回 403，原因是聊天必定
调用需要 `knowledge:search` 的全库检索。另复现本人权限查询的文字结果只输出数组大小，未列出真实权限码。

## 实现边界

- 知识上下文入口每轮从服务端加载当前有效用户。未指定知识库且没有全库检索权限时，不尝试隐式检索，
  普通聊天使用真实模型与已有会话上下文；不会为聊天授予知识库权限，也不生成知识引用或伪造检索成功。
- 显式选择知识库仍进入既有领域服务，按真实用户、租户和知识库归属检索；拒绝或服务异常不会转成空上下文成功。
  已有全库检索权限时，原检索、引用及真实错误保持不变；账号失效或权限读取异常仍失败关闭。
- 本人权限结果文字列出实际主角色、角色、数据范围、版本、分页和权限码。标识符使用完整字面量，保留下划线；
  不渲染任意链接或指令。摘要最多 1000 字符、最多 20 个完整权限码，截断时明确提示缩小关键词重查。
  当前页以外的结果由总数、页号与页大小说明，不承诺已展示全部权限。
- 不改变意图分类、ToolGateway、JWT、租户边界、确认与写发布门，不增加工具、迁移或依赖。

## 真实验收范围

浏览器测试继续使用专属 PostgreSQL 数据库、Redis 子进程、回环后端和精确可信 UI Origin。
账号没有 `knowledge:search`，只额外授予本人权限只读工具的业务权限与 Agent 权限，不增加知识库或管理权限。

同一 Workspace 会话依次发送包含随机短语的问候、无短语提示的上下文回忆、通知查询、本人实时权限查询，
随后重新回忆最初短语。真正刷新页面后，用户重新打开服务端会话，核对聊天及两种工具结果都保留。
已有小窗待办、自动跳页、切页持久性和任务中心取消继续回归。

结果必须由真实分类、模型 SSE、Controller、Worker/Gateway 和数据库产生，不拦截 API 或模拟响应。
浏览器确认正文及输入清空，后端核对普通回复、来源工具、任务及调用数；普通聊天不得创建业务任务。
测试短语只用于证明实际模型生成和上下文传递，日志只显示安全状态摘要。

## 风险与回滚

无知识检索权限的普通聊天不附加知识片段；界面中显式选择的知识库仍受既有拥有者校验。
拥有检索权限但检索配置不可用的情形仍返回真实错误，未在本节点静默吞掉。
回滚本提交会恢复聊天依赖全库检索权限及权限摘要只显示数量的旧行为；无需数据库回滚。
