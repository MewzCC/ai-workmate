# 统一业务意图入口

## 交付阶段与目标

现有 Workspace 默认聊天只对待办做前端正则识别，其他已登记业务工具依赖用户手动选择操作模式。
不能用工具登记数代替“一句话通用业务入口”。本方案分两步交付：

1. 服务端受认证的意图判定合约、失败关闭与安全门禁。
2. Workspace 自动/聊天/操作三种入口接入同一个判定与现有任务链路，移除只识别待办的生产分支。

本节点交付第 1 步；前端尚未改为自动入口，不能宣称通用意图交互已完成。
它是导航、页面上下文、真实工具和结果展示之外必要的输入路由层，不是新的工具执行器。

## 接口

`POST /api/ai/intents`，JWT Cookie 或现有认证方式保护。

输入仅允许 `input` 文本，不能为空，最多 4096 字符，UTF-8 字节数还受 `min(4096, agent.limits.input-max-bytes)` 约束。
调用者不得传 userId、tenantId、pageId、角色、权限、工具名、参数或 URL 字段，未知字段返回 400。
服务端按认证 userId 重读有效用户，要求租户与认证上下文一致且具有实时 `route:ai-workspace`。

返回沿用 `Result<AiIntentResponse>`，数据只有：

```json
{"intent":"CHAT"}
```

或：

```json
{"intent":"OPERATION"}
```

这不是授权、计划或执行结果，不返回工具参数、可执行路径、任务 ID、密钥或模型原始回答。
没有业务数据写入、会话持久化或幂等任务创建，不需要业务执行的 Idempotency-Key。

## 判定与失败语义

模型提示词版本 `oa-intent-v1`。只发送本次输入文本的 JSON，不发送附件、历史业务结果或可执行工具。
请求读取真实个人/企业/平台数据或完成实际 OA 操作判为 OPERATION；问候、一般说明、建议或示例文本判为 CHAT。
不支持或永久禁止的业务动作也应进入 OPERATION，再由受控规划与授权明确拒绝，不能在普通聊天中假装已执行。
这个规则需要真实模型语义评估，单元测试只能证明协议与失败边界，不能证明语义准确率。

严格校验返回对象只有一个文本 intent，值只能为 CHAT/OPERATION，原始响应最多 256 字符。
数字枚举、数组、重复键、额外字段、未知值、空值、尾随 JSON 或说明文字均以 SCHEMA_INVALID 返回 400，
不会剥离 Markdown 后继续解析，也不会默认 CHAT 或 OPERATION。
模型异常、线程池拒绝、超时或模型/规划能力未配置返回 AI_TASK_CAPABILITY_UNAVAILABLE（503）。
中断保留中断标记；请求不自动重试，不将错误回退为业务成功或普通聊天回答。

复用受限规划线程池；单次等待上限 `min(5000ms, agent.limits.planner-timeout-ms)`，完成或超时后取消 Future。
这限制服务端等待，不声称可以强制中断提供方已经收到的请求；底层调用仍受既有模型客户端与服务端部署配置约束。
新增独立 INTENT 限流桶：每租户/每用户每分钟 30 次，不占用现有 PLAN（10 次）或 EXECUTE（5 次）桶。
本机限流仍是现有进程内实现，未来多实例必须沿用受认证分布式策略，不能用配置放大执行边界。

## 执行链路不变

OPERATION 后续只能进入原有 plan、任务持久化、运行策略、独立工具权限、确认、execute、Worker 和 ToolGateway。
所有业务权限、资源归属、租户、版本及状态仍由 Gateway 和领域再次校验，一个任务最多一个写步骤。
分类结果不能携带或改变风险、跳过确认、开启写工具、改变租户，不能成为权限依据。
新增架构门禁阻止判定服务与控制器依赖工具、网关、Registry、Mapper 或任务规划执行 Service。

没有新增 Agent 工具、迁移、权限种子或写开关。API Key 和网关地址继续只在服务端配置。
普通显式聊天继续使用原有聊天/SSE 接口；后续自动入口必须保留这一手动选项，
以便用户在 Agent 判定不可用时主动选择普通聊天，而不是程序把失败业务请求静默降级成聊天。
自动模式会增加一次模型往返；实际调用成本和时延需要真实提供方验收，不能用 Mock 结果估算已达标。

## 验证与回滚

覆盖认证、未知身份字段拒绝、实时权限收回、租户不匹配、文本与字节边界、独立限流、
模型异常/超时、严格输出校验及不产生任务执行依赖。新参数错误文案同时提供中文与英文。
无数据库结构或业务数据变更；回滚可停用或移除新接口而保留旧聊天和受控任务链路。
前端接入之前不依赖此接口；接入后应将 API 和调用方一起回退，不恢复前端逐页面关键词执行器。

OA lint 零错误（3 条既有警告）、173 项测试与 build 通过。隔离端口开发后端启动及健康检查通过，
155 项 Flyway validate、零待执行迁移，匿名意图请求返回 401/AUTH_REQUIRED。
无迁移变更，本轮未重复执行空库/旧库迁移集成测试；未调用真实模型验证语义分类，也尚未接入前端自动模式。
