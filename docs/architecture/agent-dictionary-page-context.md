# 字典页面的 Agent 对象、版本与回执定位

## 页面闭环

本节点接通既有字典查询及六个类型/字典项创建、更新、启停工具，不新增工具、Schema、
执行接口或写开关。详情读取复用[受保护单记录接口](agent-dictionary-record-detail.md)。
页面不再把第一类或第一行当作 Agent 目标；类型与字典项均须由用户选择或成功工具回执定位。

共享结果选择器只从已成功任务的实际结果提取 `dictionaryTypeId` 或 `dictionaryItemId`。
工具代码决定封闭的 `dictionary-type/dictionary-item` 类型标签，不接受结果提供的类型、URL 或查询字符串。
持久布局与 Workspace 均先检查当前真实导航，再生成固定 `typeId` 或 `itemId` 内部参数。
相同数字的父子记录不会混用；查询列表不取首行，不从模型参数补全编号。

页面调用对应受保护详情，字典项还核验父级编号一致，允许定位当前类型搜索结果之外的实际父级。
关闭移除 URL 选择；双编号、非法编号、错号详情不形成 Agent 选中对象。
类型过滤结果不会自动更换已明确选中的对象。

## 上下文与写入

发布字段限于实际 `dictionaryTypeId/typeCode/typeVersion`、可选 `dictionaryItemId/itemValue`、
当前目标 `version`，以及已应用的类型搜索、字典项搜索、状态与分页。
`version` 在选择字典项时是子项版本，在仅选父级时是父级版本；父级版本单独保留。
新建类型无旧对象身份，新建字典项仅保留已核验父级；未提交的表单、名称、描述、身份和权限不进入上下文。
服务端页面白名单再次过滤；这些提示不替代 Gateway、领域授权与乐观锁校验。

实时 `route:dictionary` 控制读取；维护要求实时 `dictionary:manage` 与服务端类型页、字典项页及行标志交集。
编辑前重新读取受保护详情，以实际版本提交；失败保留输入和版本，成功定位实际新对象并重新读取版本。
状态、删除等人工操作仍走原受保护接口；不增加 Agent 删除能力。

列表、子列表、详情、编辑均有失效序号，用户/租户/权限快照变化、关闭、切换或卸载后迟到响应不能恢复旧对象。
确认弹窗持有销毁句柄及独立代次，取消、替换、切换与撤权后失效；已发出的写入不被假装取消，
但旧成功、失败反馈不能覆盖新选择。删除当前父级会清空父级、子列表及待处理读取，不能留下可新建子项的已删对象。
所有读写继续使用原领域服务；不通过页面或结果导航直接调用 Handler。

## 验证与回滚

组件门禁覆盖精确父子定位、非列表父级、非法/双参数、错号、关闭和乱序读写、实时撤权、
页面/行标志交集、新建无旧身份、失败保留输入、保存/启停后的实际新版本、确认销毁与删除父级清理。
共享导航验证六个写回执、固定类型及最新菜单授权；服务端上下文过滤验证敏感字段被移除。

建议前后端同版本部署；旧后端会过滤新上下文字段，不能据此放宽授权。
回滚同步回退页面上下文、固定回执定位和白名单；保留前置详情接口兼容其他调用方。
无数据库/迁移变更，不需要数据回退。本节点不等于真实模型、Worker 或全页面桌面/移动端浏览器验收；
工具总数仍为 136，人工发布门和永久禁止能力不变。

2026-10-23 验证：字典组件 24 项、共享导航 15 项及服务端上下文过滤 10 项通过。
Workspace 两项父子定位回归在移除标签传递时均失败，恢复后纳入全量通过。
独立只读审查发现的删除父级残留问题已通过反向测试修复并复核；OA 51 个文件 351 项测试全通过，
最终 lint 零错误（3 条既有警告）。Java 17 `mvn clean test` 1352 项零失败、零错误，10 项环境依赖跳过。
本轮未改数据库与迁移，未重复 PostgreSQL 迁移/重启验证；不引用前置节点的数据库结果冒充本轮端到端。
最终生产构建通过；保留既有大分包、AntD/Router 弃用及聊天输入器 NaN 样式提示。
